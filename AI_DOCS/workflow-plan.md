Model assignments below are recommendations for future work, not claims that the main chat changed models. Policy: easy → `gpt-6-luna`/low; medium → `gpt-6-sol`/medium; hard → `gpt-6-sol`/high; very hard → `gpt-6-astra`/xhigh. Split very hard work before implementation. Do not start implementation under this planning-only request. On an implementation request, first review/establish the existing uncommitted milestone baseline (B0), then freeze F1. A task becomes complete only with its listed output and verification evidence. No future task is marked complete based on this document. Claims about remote provider billing must distinguish one local logical receipt from potentially repeated external calls.
