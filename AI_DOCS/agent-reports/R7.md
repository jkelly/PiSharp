## Behavior and evidence

`PosixRawTerminalIo.IsShiftPressed()` now reads the macOS CoreGraphics `CGEventSourceFlagsState` flags and tests `kCGEventFlagMaskShift` (`1UL << 17`). It uses combined-session state (`0`), matching upstream `packages/tui/native/darwin/src/darwin-platform.m`. The import is an absolute system framework path with a C calling convention and a 64-bit flags result. Non-macOS POSIX returns false without calling CoreGraphics. Missing library, missing entry point and incompatible native image return false. Other exceptions, including cancellation, are not silently swallowed. Platform and flags delegates are injectable via an internal constructor; no terminal handle is needed to test the actual implementation.

Existing `ProcessTerminal.ForwardInput` gates native detection to Windows or macOS Apple Terminal, and only bare CR or ESC+CR. Thus Shift down rewrites these candidates as CSI-u Shift+Enter; Shift up or unavailable native support preserves Enter / Alt+Enter. Explicit keyboard protocol input and bracketed paste remain untouched. No Linux detection behavior changed.

API meaning checked against Apple's [CGEventFlags documentation](https://developer.apple.com/documentation/coregraphics/cgeventflags) and [source state documentation](https://developer.apple.com/documentation/coregraphics/cgeventsourcestateid/hidsystemstate?language=objc); the implementation intentionally retains upstream's combined-session source rather than changing to HID-only state.
