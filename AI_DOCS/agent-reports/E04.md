The daemon reuses Durable's LocalFileSystem watcher, retaining its native/polling selection, exclusion semantics, ancestor/replacement tracking, directory coverage budget, and filesystem error behavior. The operation emits ready only after coverage exists, queues any initialization changes behind ready, emits terminal errors after prior changes, and returns a tagged result only after watch cleanup. Session ownership closes races between establishing a watch and disconnect. Per-request cancellation stops the watcher without closing unrelated connection requests.

The transport queue retains at most eight path notifications, each limited to 256 KiB of conservative encoded path content; saturation or larger notifications produces overflow. The frame builder additionally checks the protocol payload ceiling before sending. Callbacks never synchronously block on the network writer.

RemoteWatcher snapshots input targets and exclusions, validates event order, maps Paths/Overflow/Failed, isolates observer exceptions, and joins the tagged watch request during StopAsync. Transport loss after ready creates a fresh subscription after 1/2/4/.../30 second delays. Re-established coverage emits Overflow; ordinary requests and old handles are never replayed. Stop wakes and joins pending recovery delays. Initial failures reject opening; terminal watch errors stop further callback delivery.

The daemon owner registers WatchOperation; the adapter owner integrates RemoteWatcher.OpenAsync. No shared connection or daemon-router file was edited by E04.
