## Limits and follow-ups

Native catalog artifacts must be self-contained single executables, including statically linked Unix PTY shim; managed development outputs with adjacent dependencies are not accepted as a deployable release format by documentation. Native publish/run and all target runtime tests belong to CI. Known-host serialization is process-local; atomic replacement protects readers, but multiple independent applications editing the same file need external coordination. Content-addressed binary pruning is intentionally explicit to preserve running daemons.
