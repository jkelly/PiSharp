## Public contracts

- `NativeDurableModelsOptions.Identity` supplies an optional default for every native chat, classifier and image request. Explicit request fields win via `ClientIdentities.Merge`; explicit `AttributionOff` suppresses a default attribution. No automatic attribution is introduced.
- I17 owns and implements `DurableRequestOptions.Identity` and identity-wrapper propagation for legacy and options overloads of classifier, image, deferred stream/fetch/cancel. Existing option-less implementations retain default-interface compatibility.
- Existing `PiSharp.AI.ModelOperations.ModelRequestOptions.Identity` already serves both classifier and image options; no parallel contract was introduced.
- `NativeDurableModels.WrapProviderHandler` installs the per-async-request hook boundary on host HTTP transports. `HasActiveProviderPayloadHook` lets hosts select HTTP when a callback must inspect the body.

## Changes

- Native chat merges the Models default before host routing or native provider preparation. Native classifier/images forward merged identity and telemetry, using the configured HTTP handler and clock.
- Web account transports wrap their provider handler, force SSE when a payload callback is active, and retain their own per-account authentication and route selection. Web deferred overloads forward request options instead of silently dropping them.
- The payload boundary can read and replace Codex zstd request bodies, preserving content headers and compression; existing re-signing support remains after replacement. Scope clears while the callback executes, preventing callback-owned requests from inheriting the hook.
- Coordinated I17 budget mapping: NativeRouteSettings receives ThinkingBudgets and ThinkingCap receives the explicit budget map.
- I17 also owns CLI adapter forwarding / active-hook SSE selection, avoiding concurrent edits to that file.
