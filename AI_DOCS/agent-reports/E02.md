## Public extension contract

`src/PiSharp.Env.Daemon/DaemonContracts.cs` defines `IEnvDaemonOperation.Name` and `ExecuteAsync(EnvDaemonRequest) -> ValueTask<EnvDaemonReply>`. Requests expose parsed JSON, raw bytes, request/session cancellation, kill-mode state, bounded serialized event writes, session state and `Own(IAsyncDisposable)` cleanup registration. Extensions throw `EnvDaemonException` for stable wire codes and optional details. `EnvDaemonOptions.Operations` supplies explicit registrations. `Program.cs` composes E04 watch, E05 process and E06 terminal factories; no downloaded/external runtime is used.

The session registers a request before scheduling it, runs file operations through a 16-worker semaphore, orders operations on the same file handle, orders process-input operations by target, and dispatches terminal controls on the input reader in arrival order. Control frames take priority over command output and large replies. Queued bulk output is limited to 4 MiB (a single large result may occupy that whole budget); output producers bound their own chunks so the framing layer preserves UTF-8 and raw byte semantics. All frames have one writer. Ping is every five seconds and silence timeout is thirty seconds, observing every input read including partial frames. Complete malformed JSON receives EINVAL; malformed framing ends the connection. EOF, signals, disposal and silence cancel the session and dispose owned file/process/watch resources. Shutdown drains for at most two seconds, matching upstream's ability to exit with a blocking raw FIFO worker still pending. Handle admission closes synchronously before draining: a late native open is disposed rather than admitted, and late plugin ownership is disposed immediately.

## Filesystem implementation

All protocol filesystem operations are implemented: lstat, realpath, write/writeChunk, truncate, fsync, rename, mkdir, rm, mkdtemp, open/pread/fstat/scanLines, opendir/readdir/close, and listFiles. Handles are connection-local, monotonically assigned, limited to 4096, and disposed on disconnect. A failed chunk invalidates its write handle. Short mutations are not replayed. Scan/list cancellation is request-scoped. Reads use the opened descriptor across replacement; fstat obtains native descriptor identity, size and nanosecond timestamps on Windows, Linux and macOS. Durable's LocalFileSystem supplies established mutation/realpath/list semantics and LineScanner supplies bounded UTF-8 line accounting.
