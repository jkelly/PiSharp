## Confirmed findings

### [P2] Missing document text is silently exported as a successful empty document

Location: `samples/agents/61-DocumentRedactionAssistant/Workflow.cs:46` (with successful export at lines95–105).

`Redact` reads the required source with `doc.Text("text")`, whose shared helper defaults a missing/null property to an empty string. The document still passes format validation, obtains a hash and zero detections, and is marked `detectedValuesAbsent: true`. With approval, the workflow exports an empty file and claims success. Missing source material must produce an explicit validation error; it should not be equivalent to an explicitly supplied empty document.

Reproduction: clone the sample61 fixture, remove `documents[0].text`, and invoke the existing DLL with `--demo --approve --input <modified-fixture> --workspace <fresh-directory>`. Observed exit0, `success=true`, all four tools successful, and `redacted-letter-1.txt` length0 bytes.

Evidence workspace: `C:/Users/jksof/AppData/Local/Temp/pisharp-review61-7b76b629bccb400a8846c164efe4957d` (`missing-text.json`, `workspace/report.json`, and the zero-byte export).

Suggested correction: require `text` to be a string property before reading it. Preserve a deliberate policy for explicit empty strings, and test absent/null/wrong-type text through the full tool sequence.

### [P2] The redaction marker causes valid sensitive names to fail verification

Location: `samples/agents/61-DocumentRedactionAssistant/Workflow.cs:79`, together with marker insertion at line70.

Every matched span is replaced by `[REDACTED]`, then `Verify` searches the complete generated string for every original matched value. Case-insensitive sensitive literals such as `Ted` or `Ed` occur inside the replacement marker itself. Thus a correctly sanitized document is rejected before even the detection stage can complete. The supplied-literal contract allows these names (minimum length2), so this is not an unsupported-pattern case.

Reproduction: set the first fixture document's `text` to `Ted` and `sensitiveLiterals` to `["Ted"]`; invoke the existing sample61 DLL with `--demo --input <modified-fixture> --workspace <fresh-directory>`. Observed exit1, `success=false`, and `detect_sensitive` error `Sanitization verification failed; a detected value remains.`

Evidence workspace: `C:/Users/jksof/AppData/Local/Temp/pisharp-review-feca16b8d591484da5967074250470d3` (`ted-literal.json`, `redaction/report.json`).

Suggested correction: verify retained original source segments separately from replacement markers, or use a replacement strategy that cannot be confused with source evidence. Include short/common supplied names such as Ted and Ed in tests.

### [P2] Malformed calendar busy records are treated as free time and can be booked

Location: `samples/agents/33-CalendarSchedulingCoordinator/Workflow.cs:58` and `:78`.

Both inspection and collision checking use `OfType<JsonObject>()` on the calendar arrays. Non-object rows are silently discarded instead of rejected. A present-but-unreadable busy record therefore turns into no busy record, allowing the approval-gated booking to certify a slot as shared free time without complete interval evidence. Existing interval validation does not run for the dropped entry.

Reproduction: replace `people[0].busy` in sample33's fixture with `[null]`; invoke its existing DLL with `--demo --approve --input <modified-fixture> --workspace <fresh-directory>`. Observed exit0 and `success=true`, booking `meeting-a` at `2026-11-02T15:00:00Z` (the normal valid fixture starts at15:30Z). The malformed row should stop inspection/planning rather than permit the earlier booking.

Evidence workspace: `C:/Users/jksof/AppData/Local/Temp/pisharp-review-feca16b8d591484da5967074250470d3` (`calendar-null-busy.json`, `calendar/report.json`, `calendar/booking-meeting-a.json`).

Suggested correction: validate that every available/busy element is an object before converting it, then validate each start/end interval. Add malformed null/string-row cases and assert no booking file is created.
