## Contracts and implementation

- Wrote `docs/contracts/node-overlay-handles.md` before implementation. Overlay options resolve once after the async factory, matching upstream. Function visibility stays in Node, receives current dimensions, has a one-second UI deadline and at most one in-flight request per component. Frame wait cancellation cannot grow a queue behind a blocked Node predicate.
- Remote handle mutations are ordered notifications with sequence acknowledgements. Reads use a UI snapshot, never dispatch back into the UI loop while Node is answering render/visibility. Native `CaptureSnapshot` deliberately does not evaluate the predicate. Host snapshots refresh after rendering and handle operations. Node reflects pending own mutations until acknowledged.
- Components carry runtime generation in their IDs. Double `done`, synchronous `done` during construction, async late factory settlement, invalidation, stale handles, and `onHandle` rejection have explicit lifecycle handling. Invalidation sends one component completion before the handle becomes inert; delayed component disposal happens once.
- `unfocus()` uses native focus restoration. `unfocus({target})` to arbitrary Node component objects remains unsupported because those objects have no general native identity; this transport limitation is explicit in the contract and user docs.

Root approved a separate runtime upgrade contract before pins changed. `PiNodeRuntime` now selects Pi1.5.0 with policy `no-default-attribution-v1`. Both default and configured locations use a version/policy child. Existing caches are never deleted or overwritten; unverified targets produce explicit compatibility fallback. Lockfile/registry integrity verification, undici8.12.3, TypeBox1.3.27, jiti2.7.0, aliases and offline fallback remain.

`pi-modules.mjs` loads the real agent-core module and sets its exported `DEFAULT_AGENT_IDENTITY.attribution` to null before other installed imports. This retains Agent and dependency identities across native ESM and jiti and preserves explicit caller attribution; incompatible export shape fails clearly. The installed SDK also builds identity from telemetry settings, so the Node child defaults `PI_TELEMETRY` to `0` while preserving an explicit existing environment value. Root installed the exact published packages in `artifacts/node-runtime-150` (123 packages, lifecycle scripts disabled), independently of the read-only upstream source tree.
