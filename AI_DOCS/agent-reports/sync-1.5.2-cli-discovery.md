## Changelog applicability and evidence

### CLI-SESSION

* **Missing folder fork, startup/resume/import/extensions (#11975), required.** Native PiHost.PromptMissingSessionCwd currently returns a cwd string, StartupUi offers only Continue/Cancel, PiCommand only reopens with CwdOverride; PiSessions.MissingCwdPrompt still old multiline text. Interactive /import copies via `context.ImportSessionFile` before switch and has no rollback. Implement typed `MissingSessionCwdChoice { Continue, Fork }` nullable for cancel, shared option labels naming fallback cwd, startup Fork via PiSessions.ForkFrom (new ID + parentSession), interactive/extension switch prompt and override/fork flow. Track exactly which import/fork file is newly owned; delete it when validation fails or switch vetoes, never delete an already-stored source. Reuse native fork/write and transition authority, not an ad-hoc JSON mutation.
* **Disposal waits active tools and records their results (#9126), largely already implemented.** ReplaceableAgentSession.StopAdmissionAndJoinAsync and PersistentAgentSession shutdown retain/join original work before catalog/extension teardown. Verify with existing lifecycle regressions; do not replace this stronger ownership design with TS `abort()` call.
* **RPC idle ctx.shutdown / prompt response before shutdown / EOF+signal cleanup (#11599), already implemented.** RpcSessionDispatcher ScheduleIdleShutdownCheck, joined input/command/run gates, BeginShutdown single task; ShutdownSignals first signal cancels, second force exits; RpcSessionCommand cleanup drains dispatcher then runtime. Required regression evidence, no new broad shutdown rewrite.
* **Reload during run/compaction (#9222), already implemented through replacement reservations.** Native reload obtains session authority and refuses busy operations; verify exact runtime behavior and guard before effects. Preserve existing join semantics.
* **Prompt/tree overlap (#9155), existing native input/replacement reservation likely covers it.** PersistentAgentSession reserves prompt operation before admission/hooks; tree navigation participates in same gate. Verify asynchronous hook and summary race, don't introduce duplicate independent boolean flags.
* **Thinking restored on branch (#11451), partly ported.** PersistentAgentSession.ThinkingPersistence.cs exists and invoked before prompt. It compares context.ThinkingLevel literally to configured level; upstream compares recorded level after model clamp, so ensure a requested xhigh clamped to high is not overwritten on ordinary prompt. Requires targeted regression.
* **Model cycling outside scoped/available list (#11806), missing.** InteractiveMode.Session.cs returns early at count<=1 and uses `(index<0 ? 0 : index)+step`, skipping first forward. Shared helper returns null for empty or current sole member; out-of-list forward index 0/backward count-1, including singleton. Apply both scoped and available paths and native RPC `cycle_model` implementation if separate.
* **Queued images (#11738, #8612), missing native normalization hook found.** Idle source path only PiInitialMessage processes images; no equivalent prompt/queued delivery image normalizer found under CodingAgent/Rpc. Required contract: normalize delivered user image content using current model resize limits before public events/persistence/transport, preserve non-image blocks, append hints, allow image-only queue entry removal. Use lifecycle-delivery hook with stable identity, not text matching. Separate CLI-INPUT owner advised.
* **Prompt argument apostrophes/escaped/unclosed quotes (#11861), already ported.** PromptTemplateExpander.ParseCommandArgs already has token-start quote rule, quoteStart fallback and matching-quote escapes (source 96667f34 comment).

* **Edit mixed EOL / bounded diff before write (#8544), missing.** Native DiffFormatter still computes whole-file Myers arrays with MaximumLines 8192 and EditPlan/Matcher normalize then output paths need check. Contract: retain replacement ranges into original input; only replacements use local line ending, preserve untouched mixed CRLF/LF/lone CR; compute bounded surrounding diff windows and firstChangedLine before admitted write. Keep native explicit-policy bounded failure contracts; default Pi path must support localized edit to a large file. Test failed diff cannot write.
* **PowerShell 5.1 stderr false failure (#8842), missing.** ShellConfiguration command construction has no NativeCommandError correction suffix. Append source suffix only for basename powershell.exe and commands not ending in backtick: newline-semicolon + `$?` success, then `$LASTEXITCODE -eq 0` and `$Error[0].FullyQualifiedErrorId -like NativeCommandError*`, else exit1. Keep parser errors and explicit exit behavior; no change pwsh.
* **Unicode truncation (#7121), mostly ported:** UnicodeText.SliceHead in PiGrepTool, existing output truncation byte boundaries; D-SCH owns codemode/MCP strings, summary snippets need narrow check.

- Interactive runtime chooser shared through actual host link; Continue preserves file/header/ID; Fork creates a new session file and ID; cancellation/veto rolls back owned fork.
- `/import` removes newly copied file on cancellation/failure (never pre-existing source); imported Fork retains original import source in parentSession and removes temporary copied file. Temporary provenance registrations release in finally.
