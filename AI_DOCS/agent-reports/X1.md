## C# representation and ownership

`Support.cs` contains `ViewBridge`: the Durable view types and delta operations are
distinct from Chord's `JsonNode` types. This explicit adapter projects the exact
entry-kind/task-count data consumed by these examples and forwards replacement
frames, retirement, terminal errors, cancellation and the real observation's
detacher. `self.Follow` owns the attachment and computes Chord deltas from the
projected values. `EmptyDurableModels` is the existing no-provider model catalog;
all executed work is deterministic application tasks and requires no credentials.

Example 35 closes the host and opens another host on the still-owned store before
closing/reopening the database. It then reads both the Chord table row and Durable
transcript from disk. Example 37 closes the actual Session; the self-followed task
graph fails the core, the separate transcript object fails with its followed view,
and an explicit reference retry opens a new Harness over the same store.

H1 was notified of the real native-open Harness scheduler's cross-thread registry
reads. H1 supplied the dispatcher-backed registry wrapper for both host and self
registry access; X1 made no changes to H1/H2 internals or the Store/RegistryReader
adapter.
