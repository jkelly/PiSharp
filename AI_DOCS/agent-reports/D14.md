## Reusable implemented foundation

* `src/PiSharp.Chord/Contracts`: branded `Contract`, `HostKind`, `Address`, `Schemas`, immutable schema snapshots, histories, version adaptation and fingerprints. This is already v2, using JSON Schema. **Do not introduce generic replacement contract types.** Existing `Contract` has no type parameter: parameters are `JsonObject` and implementation members are name-bound (explicitly recorded in `Contracts/Index.cs`). Principal is `JsonObject` with `kind`; the existing `PrincipalKeyFunction` is `string(JsonObject)`.
* `State`: real `Batch`, JSON sources/derives, native sources/writables, watch adapters. Batch has publication/reentrancy/compute/flush ordering. Host must supply `schedule(Action)` which runs later and serializes host work; ThreadPool default is not a production host serialization policy.
* `Documents`: real object-scoped `Documents`, `Line`, `SealToken`, transaction `Stage<T>/Staged<T>`, staged `Adopt/Committed/Discarded`, persisted slots/residency/migrations. `ITx.Start` is missing but all staging primitives already exist.
* `Store`: real Chord store, tables, owner claims, allocator, commit series, deferred writes, import/export/history. `ChordStore.Attach(Attachment(Action<Exception> failed, Batch batch))` enforces one attached host. `Detach()` releases the attachment; the application retains store ownership. No new database engine or schema is needed for W19.
* `Registries`: `RegistryRecord`, `RegistryContribution`, `RegistryValueSource<V>`, version adapters, lazy/batched composition and waiters. Required calls are `Serve`, `Add/Remove`, `ComposeServed`, `Value<V>`, `Read`, `Wait`, `Close`. Host integration is absent; algorithms are already implemented and exercised.
* `PiSharp.Durable.Store`: real `StoreStorage`, owner-scoped tables/documents/commit series, SQLite backend adapter, `RegistryReader.Create(IRegistryValue<IRegistrySnapshot>, ChordContext)`. `StoreStorage.Publishing` uses the attached Batch. Keep these APIs; replace hand-built integration evidence with actual host callers.
* `tests/PiSharp.Chord.Tests/Registries/RegistryHost.cs` is explicitly a **test surrogate**, useful as an algorithm map only. It lacks plugin staging/refusal, lifetime states, backoff, real dependency parking, reload, publication promise and close coordination. Do not promote it into production as the implementation.

## Architecture decision

Keep one dependency direction: `Contracts + State + Store + Documents + Registries -> Host -> Jobs/Remote integrations`, with Jobs and Remote using **small host interfaces** rather than owning Host internals. `PiSharp.Durable` stays independent of Chord; `PiSharp.Durable.Store` remains the join. Chord's existing `[Experimental("PISHARP_CHORD001")]` stays. Packaging is a final gate; neither current `IsPackable=false` project should be published just because it compiles.

The public host surface is name-bound (matching existing Contract): factories return a `HostImplementation` containing `Variant?` plus a name->member map. A member is an actual Chord watchable/keyed handle or a method delegate; host validates it against the contract. A reference exposes lifecycle, `Member(name)`, `KeyedMember(name)` and `CallAsync(name, args, context)` rather than pretending C# has TypeScript mapped properties. Convenience typed overloads may wrap these, but runtime validation and semantics are shared.

Use a host-owned FIFO synchronization context/dispatcher, carrying asynchronous continuations back onto it. **Do not serialize an entire async operation by holding a SemaphoreSlim until it completes**: a pending get, native open, run, route resolution or dependency may require another queued host operation to complete. Serialize state transitions, run external asynchronous effects outside locks, and reenter for adoption. Existing Batch/registry/source operations run only on that dispatcher. Synchronous `Hold`, declarations, value reads and release need a dispatcher invocation contract (inline only when already on host; external caller marshals synchronously). Never invoke a user callback while holding the dispatcher queue lock.

### Fixed public shape for the native host package

Names below are the proposed C# mapping, to be fixed in the first implementation package rather than guessed independently by every worker:

```csharp
// Namespace PiSharp.Chord.Host; Contract, Address, StateDefinition etc are existing types.
ChordHost Hosts.Create(HostOptions options);
Task<LoadReport> ChordHost.LoadAsync(IReadOnlyList<PluginFacet> facets, ChordContext context);
Task<ReloadReport> ChordHost.ReloadAsync(IReadOnlyList<PluginFacet> facets, ChordContext context, ReloadOptions? options = null);
Task<IReference> ChordHost.GetAsync(Contract type, JsonObject parameters, ChordContext context, GetOptions? options = null);
IReference ChordHost.Hold(Contract type, JsonObject parameters, ChordContext context, GetOptions? options = null);
Task<IRegistryValue<V>> ChordHost.RegistryAsync<C,V>(Registry<C,V> registry, ChordContext context, GetOptions? options = null);
Task<T> ChordHost.RootAsync<T>(Func<CallContext,Task<T>> work, ChordContext context, RootOptions? options = null);
IWatchable<...> ChordHost.References(Contract type); // actual presence records, with params/principal/incarnation
IWatchable<...> ChordHost.Activity { get; } // references/calls/jobs/lingering, baseline counts
Task ChordHost.CloseAsync(ChordContext context);
```

`HostOptions`: `Address?`, `JsonObject? Principal`, `PrincipalKeyFunction?`, telemetry, required `Action<HostError> OnError`, close timeout default 30 s, ready timeout default 60 s, heartbeat ping/close 15/30 s, revocation selector, optional compressor, optional `IStore`. Add `TimeProvider` for deterministic tests and an explicitly supported scheduler only if it preserves single host ownership. RootOptions must preserve **omitted principal vs explicit anonymous principal**; plain nullable property alone loses this distinction. Do not expose a private Batch/Registry error type publicly: HostError carries public discriminated record types and preserves original exceptions.

`PluginFacet(name, facet)`; `Facet.Define(Action<IFacetHost,IFacetSelf>)`; `IFacetHost.Serve(Contract, HostFactory, ServeOptions?)`, `Serve<C,V>(Registry<C,V>, RegistryProvider<C,V>)`, `References(Contract)`; facet self only `Contribute`. Setup is synchronous and declaration-only; retained facet APIs reject after setup. `ServeOptions`: older-version accepts mapping, linger (default 0), untraced. `HostFactory` receives parameters, principal and `ISelf`; local ignores principal. `IStoreSelf` extends ISelf for the local empty-param shape that may persist/contribute.

`ISelf`: state declaration, derives (mixed JSON/native sources), synchronous dependency Get, registry dependency, writable, retryOn, native Open, object Tx, Follow, job declaration. Existing state declaration returns singleton or keyed handles; offer explicit `State/KeyedState` overloads instead of returning an object that callers cast incorrectly. The factory checks duplicate names/kinds and the returned implementation in one place. Methods receive a `CallContext` that **contains** a `ChordContext` (the existing ChordContext is sealed), principal and incarnation; it owns call-scoped references and seals after settle.

`IReference`: `IWatchable<RefState> State`, `string? Variant`, `IWatchable<JsonNode?> Member(string)`, keyed member access for local shapes, `Task<object?> CallAsync(...)`, `Retry()`, idempotent `Release()/Dispose()`. A result may be bytes/non-JSON if its contract permits; do not force all method values through `JsonNode`. `RefState` has loading/live/failed/released with failure cause and retry time, not a single bool. Invalid params throw synchronously; absent providers wait through initial publication then become waiting failures. Acquisition does not leak a reference on cancel/timeout.

### L1 — V2 wire, parts, codecs and transports (independent now)

Own `src/PiSharp.Chord/Link/**`, matching link tests and offline TypeScript golden generator. Base only on `packages/chord/src/next/link`, `next/data/errors` protocol constant and `next-node/compression.ts`. Public `ILink` carries **bytes**: Send, OnMessage, Close, OnClose, with late listener/backlog semantics, one listener and idempotent close. Codec has Encode/Decode; Message is a checked tagged union. Expose MemoryLinkPair, WebSocketLink and an IPC abstraction. Node's IPC transport is not .NET stdio: keep a deliberate framed pipe adapter and a distinct Node interoperability adapter; do not claim arbitrary Node child compatibility from raw stream writes.

`Channel` owns handshake and message validation, never host lifetimes: hello first with protocol/incarnation/calls, refuse mismatch/missing/duplicate hello; trusted bypasses envelope schema validation only; codec bounds/framing still enforced. Handler opened/message/closed; message may await inflate so all later messages queue in order, and close clears them. Host drives heartbeat via deterministic time. Wire and decoded per-part bounds: default 16 MiB/64 MiB untrusted, no implicit bounds for trusted unless set; native compression threshold 16 KiB. Params never compressed; compressed arguments from child are protocol errors. Bytes-segment support follows method schema and exact omission. Export internal Part/Channel types needed by R1 only through assembly internals.

Tests: exact binary/text bytes from v1.5.0, Unicode/lone surrogate/bytes segments, malformed/truncated/oversized envelope/parts, deflate round trips and bomb limits, header mismatch, messages received before listener, mid-send/late close, asynchronous inflate ordering/cancel, fake WebSocket/IPC failure. Protocol v2 frame window is not legacy protocol4's byte window.

### R1 — V2 remote objects, calls, routes, relays and revocation

Depends on H1 target/dispatcher seam and L1. Own `src/PiSharp.Chord/Remote/**`, `Host/RemoteIntegration.cs`, `Host/Route.cs`, and matching remote/route/revocation tests. Never independently edit Host's registry/object lifecycle.

Public Host additions: `Accept(ILink,LinkOptions,ChordContext)`, `Connect(...)`, `Route(HostKind,RouteOptions,ChordContext)->RouteHandle`, `Revoke(JsonNode,ChordContext)`. LinkOptions principal/trusted/codec/part limits. Routes registered before load; one per kind; authorize each hold, resolve a distinct address on demand, retry once after a successfully handshaken link drops, no reconnect timer. A link resolved after initiating reference disappeared is still admitted. Dead link not retained. Connect rejects replacing open parent. Parent may forward principal/incarnation; child and route cannot impersonate by supplied fields. Unknown ids ignored before allocation/counting; reusing live ids is protocol error.

Remote target keeps path across reconnection; calls never replay; pre-live calls park bounded by ready timeout. Per-origin provider K=2 bound/state messages in flight and N=256 calls; control never blocked. One batch applies all remote entries before ACK; prepare/validate entire frame before any adoption. Full window folds pending ops at leaf and switches to replace after cap; binding/state fair scheduling. Relays forward parts without decoding/recompressing, preserve upstream ACK attribution and isolate slow origins. Origin ids never reused, downstream close sends one closed-origin per upstream rather than replaying per-hold releases. Per-hold replicas use separate codecs/decoder state. Member removed/reappearing across variant/reload emits failure/replacement correctly. Oversized owned part fails that hold and releases it without killing unrelated entries; malformed structural messages kill link. Revocation ends active and not-yet-bound matching work, aborts its calls, closes child connections, forwards only to routes, never revokes own/parent implicitly.

Tests: upstream `next/remote/*`, host route/revocation, examples 08–17; two child clients/one slow, multi-hop origin isolation, post-drop late callback ignored, principal spoof, queued args and call abort, reload while old indexed binding in flight, all-frame-or-none adoption, compression owned vs relayed, active chain cycle/hop bound, route resolve outlives request.
