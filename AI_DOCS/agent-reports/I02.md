## Changes

* C02: non-strict input schemas preserve root `$defs` and `definitions`; the shared converter covers normal declarations, unsupported-prefer fallback, explicitly disabled preferred strict tools, and native inline additions. Required strict behavior remains unchanged.
* F08: `AnthropicMessageThreadStore` retains only bounded session identifiers, SHA-256 prefix hashes, counts and reply IDs. Generations consume continuation once and prevent late responses from reviving cleaned sessions or overwriting a newer concurrent run. A store defaults to 10,000 entries; oversized response IDs are not retained.
* Eligibility defaults to exact provider `anthropic` at exact host `api.anthropic.com`, with prompt caching and nonempty session ID. Nullable `SupportsMessageThreads` overrides the default. I06 supplies shared catalog compatibility mapping; route and live selection metadata also forward it. Gateways require explicit opt-in.
* Structured key and authenticated factory requests carry per-request metadata, including final hook-adjusted payload and a rebuild delegate. The HTTP layer never reads an arbitrary request body to discover it. It sends a full `create` initially and a suffix `continue` only when endpoint, fixed settings and normalized prefix match. Caller beta-header overrides retain precedence.
* Known pre-stream continuation failures retry full `create` once; unsupported requests retry stateless once and disable future threading for that session. Strict-tool fallback remains independently bounded. Both fallback kinds preserve diagnostics; ordinary and in-stream failures are not retried by this feature.
* Successful post-cleanup replies update state only when they have a response ID, no fallback model, and the operation is uncancelled. Failed/abandoned streams do not commit state.
* Review correction: authenticated requests retain the effective projector options, including authentication-selected OAuth mode, for reply replay. The prior raw caller options incorrectly hashed canonical `read` instead of wire `Read` and forced full requests after OAuth tool turns. A resolved-auth fake HTTP tool-turn test exercises both name conversions and the next continuation suffix.
* `ChatRequest.DisableContinuation` bypasses reads and writes. `CacheWarmingPolicy` in the AI package shares TTL, delay, economics, eligibility and replay settings; existing `CacheWarmer` public entry points wrap it. CLI cache replay applies the independent-request bit.
