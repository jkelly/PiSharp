## Changes

- `McpStreamableHttpTransport` now recognizes CR, LF and CRLF immediately. A single pending-LF flag spans reads, so split CRLF does not become an extra blank line. Byte buffering, UTF-8 decoding per complete line, BOM handling, event data accounting and existing limits remain in place.
- `McpSignIn` attempts stored registered-client refresh before dropping credentials because the interactive callback moved to a free port. The temporary OAuth host uses the registered redirect URI. Successful refresh preserves client metadata/redirects and rotates tokens through the existing persistence path. A browser fallback closes the temporary host, reloads state, then applies the existing callback compatibility rules and skips a duplicate refresh. Existing configured-client, explicit CIMD and step-up branches retain their behavior.
- Added dedicated SSE tests covering every byte split (including UTF-8 and CRLF), one-byte reads, mixed line endings and dispatch while the response remains open; cumulative event and line overflow plus an exact-limit line.
- Added dedicated OAuth tests using a real occupied loopback callback port plus in-memory authorization/token endpoints: successful refresh without browser/registration, cancellation retaining original client/tokens/state, and failed-refresh browser fallback registering the free callback port and exchanging the code against it.
