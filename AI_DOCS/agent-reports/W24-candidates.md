## Unicode disposition

`tools.tool-search-unicode-words` remains an explicitly supported C# alternative to pinning V8's ICU. The implementation uses system ICU for dictionary word segmentation and falls back to space-separated runs when it is unavailable. Invariant globalization keeps .NET NFC behavior (normalization becomes a no-op); Greek final sigma retains .NET invariant casing (`ΟΣ` → `οσ`) rather than claiming ECMAScript contextual casing (`ος`). None of these documented fallbacks is silently removed.

Added `UnicodeProfileCases.cs`: the test executable launches itself twice with `DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=0` and `=1` set only on the child. Profiles verify Greek final-sigma output, precomposed/decomposed accented words, Chinese and Thai segmentation, and direct deterministic no-ICU fallback. The report includes actual system ICU library path/symbol suffix or unavailable fallback, plus observed NFC availability. Test-only friend access exposes internal diagnosis/fallback without introducing a public API or user-visible UI configuration.

This work is separate from I08's UTF-16 scalar-safe truncation and I03's schema-reference traversal. I03 authorized the helper edits; its ranker traversal changes are preserved.

Test: `unicode.profile-normal-invariant-and-fallback` in `PiSharp.ToolSearch.Tests`. Existing `sync150.tool-search-unicode-words.*` are still the full-feature host controls. The new profile deliberately asserts backend-dependent supported behavior instead of pretending all ICU versions are V8-equivalent.
