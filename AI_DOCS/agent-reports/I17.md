# I17 — Durable stored policy and stream controls

Requested assignment: gpt-6.1-sol / high / Ultrafast. Effective service tier: unverified (not exposed by the delegation runtime). No subagents, commits, live credentials or paid API calls.

## Implemented

- **F01:** `AgentChange.Compaction` is a clearable whole-object patch; `Agent.Compaction` resolves the stored `pi.agent` object. Supplied token counts, including model overrides, must be finite safe integers at least zero. Stored values copy the source object. Existing rewindable document creation handles forks and task-owned child inheritance without a schema bump. Policy precedence matches upstream: conversation model override, harness model override, conversation fields, harness defaults; explicit conversation disabled beats a harness model enabled flag. Threshold, pre-task background selection, overflow recovery and manual summary sizing read the same resolved policy.
- **F02:** `ITx.GetSubmissionAsync(SubmissionId)` exposes the existing concrete committed lookup. Its existing `Read` path retains post-write rejection and settled-transaction rejection. A default interface implementation throws `NotSupportedException` for external `ITx` implementations that have not implemented the new read, preserving their source compatibility instead of silently supplying a different read path.
- **F03:** `ConversationStreamOptions` and `DurableStreamOptions` carry nullable `ThinkingBudgets` (immutable JSON object) and `WebsocketConnectTimeoutMs`. Generation and summary checkpoints serialize/read these with upstream key spelling. An in-flight request resumes its pinned values after reopen. Native token-budget routes cover Anthropic, Google and Completions. Host routes cover their fixed/catalog/authenticated variants, Vertex and Bedrock; Codex receives the per-request handshake deadline. Per-request host connections are disposed with stream enumeration, keeping changing options isolated from shared cached routes.
- Coordinated with I21: `DurableRequestOptions.Identity`, all `DurableModelIdentity` wrapper overloads, CLI deferred options forwarding, and the active payload-hook SSE guard. Native core identity and HTTP hook implementation remains I21's work.

## Compatibility

The new agent/checkpoint JSON fields are additive and require no storage table/version change. New runtimes reopen old documents/checkpoints without the fields. Old runtimes ignore the new policy/stream fields and therefore do not enforce their semantics; downgrading while relying on them is not equivalent behavior. Existing third-party `ITx` implementations continue to compile but must implement the newly exposed member before callers can use submission lookup.

Native public Anthropic/Google projection option records gain optional `ThinkingBudgets`; the Vertex factory gains a trailing optional parameter. Existing call sites remain valid. Defaults remain unchanged when the new settings are absent.
