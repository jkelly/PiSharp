## Implemented behavior

- Public byte-only `ILink`, shared late-listener/backlog/idempotent-close implementation, asynchronous FIFO memory pair, connecting WebSocket buffering, native System.Net.WebSockets adapter, and length-prefixed native framed pipe adapter. At N1's request, the native WebSocket sender closes slow sockets above 4 MiB of waiting frames (configurable; excludes the active send), matching the next-http adapter boundary.
- A separate `INodeIpcPort`/`NodeIpcLink` structural bridge for an actual advanced-serialization Node IPC owner, including non-byte application-message skipping and false-send backpressure. Framed pipes are explicitly **not** advertised as Node child-process IPC compatibility. No Node process bridge is claimed by the fake-port case.
- Internal checked message records for every pinned kind, origin validation, safe numeric framing, protocol error envelopes, and byte-for-byte binary/text encoders. Includes padded five-byte long-string lengths, strict incoming UTF-8, isolated-surrogate JSON preservation, exact optional omission, opaque deflated parts, and byte-segment markers/views.
- Raw DEFLATE compressor and bounded inflate. A DEFLATE structural preflight detects truncated input which .NET's DeflateStream alone can accept as EOF. Async inflate runs off the host dispatcher, polls cancellation, leaves no result after close, and records the upstream telemetry counters when a context is supplied.
- Per-part untrusted defaults 16 MiB wire / 64 MiB decoded; trusted defaults unlimited. Wire size is checked before inflation. Compression threshold is greater than 16 KiB UTF-8 and only keeps compressed data if smaller. Segment bytes remain transport-bounded, as in the baseline.
- Channel sends hello first, queues outbound messages before greeting, rejects missing/duplicate/mismatched greetings, applies envelope checks only when untrusted, sequences asynchronous handlers (including queued heartbeat frames), drops queued work on close, and supports deterministic owner-driven heartbeat ticks. Host/reference lifetimes remain R1/H1 responsibilities.

Public/internal shapes were sent to H1 and R1 before their integration. R1 consumes the existing Message, Part, codec and Channel types; its owner boundary rejects compressed params and compressed child arguments and keeps relay parts opaque.
