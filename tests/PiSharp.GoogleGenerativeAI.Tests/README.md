# Google Generative AI authored offline consumers

This new project exercises the real native request factory, incremental HTTP adapter, existing reducer, ChatClient, frozen catalog binding, ModelTransportRegistry and high-level Agent. Every expected request/event value and injected response is authored from static pinned Pi source reads. The unchanged Google catalog JSON is released metadata, not a captured Google execution.

All 14 families are uncompiled and unexecuted in this source milestone. No C# parser/compiler, native DLL, provider execution or new Source capture was used. The runtime window is closed. A future approved window must perform real restore, build and serial execution before any native result is reported. The AI plus Agent project graph differs from the allocated AI-only lock candidate, so no lock was fabricated/copied.

Use no arguments for all serial families, or --case <exact id from authored-cases.json> for one family. The runner retains each original test task. Its diagnostic deadline produces INCOMPLETE_NONPASSING, stops later admission and joins the original; timeout does not count as cleanup or acceptance. Test finally blocks release every authored held gate and join original runs.

Program output identifies the exact test, AI, Agent and Contracts assemblies by SHA256. Future evidence must additionally bind the source commit/tree, project/lock bytes, SDK/runtime identity and companion executions. Tests do not close P2-08, Google/Vertex coverage, any whole-package scope or phase gate.
