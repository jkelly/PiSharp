# Inspect a repository fixture

Summarize project layout and identify missing onboarding material.

Run `dotnet run --project samples/agents/22-RepositoryOnboarding` for the fixture demo, or append `--self-test` for the deterministic tool check. The demo writes artifacts to the runner workspace. `--input` accepts a replacement JSON fixture and `--workspace` selects the output directory.

The fixture is illustrative; no repository or external service is changed.
