## Derivative fixtures

Some reference fixtures contained an author's absolute home-directory path. Public copies use the synthetic root `P:/PiSharp/root`. This root is a fixture identity, not an existing directory, a trusted oracle installation, or permission to execute anything. The transformation preserves path suffixes, separator style, case, and identity relationships. The completed path phase changed string values; it found no path-valued object keys requiring replacement.

These files are **path-normalized derivatives, not original raw captures**. Historical fields inside them describe the original execution. In particular, an original capture's normalization list, execution flags, harness hashes, source hashes, or qualification receipt hashes do not certify the public derivative. They are retained historical observations.

Every non-path behavioral value is preserved. Embedded content hashes and encodings are updated only where they describe normalized content. Current fixture inventories and test integrity checks bind the public bytes; historical execution and admission identities remain separate. An exact-path, original-hash, original-length mapping is required wherever a current verifier needs to resolve a historical harness pin to reviewed derivative bytes. Unknown tuples are rejected.

The public export manifest contains safe repository-relative file identities and original/current hashes and lengths. Detailed reversible pointer/value mappings and private capture originals remain outside this repository. They are not public raw evidence. No private actor logs, active grants, or developer credentials are included.
