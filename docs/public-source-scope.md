## Inputs deliberately omitted

Acquired Pi source/npm archives, embedded native/WASM/ZIP assets, generated reference corpora, genuine oracle captures/goldens, local source inventories, private admission/compilation receipts and workflow evidence remain outside this tree. No private Git ancestry is imported. Original private histories and evidence remain intact locally.

The original complete solution/gate needs these inputs. Agent tests copy two reference golden files at build time; reference tests inspect a retained npm archive and frozen model metadata. Those projects/inputs are excluded from the public test solution. Extending the public corpus requires disclosure/rights review and fresh regression evidence.

The omitted source archive contains the Pi MIT root notice plus native prebuilds, WASM and a nested harness ZIP with unclosed item-specific rights/notice delivery. The npm archive lacks a named packaged license file. The pinned public source grant and [third-party notices](../THIRD-PARTY-NOTICES.md) support copied/adapted source, not complete archive redistribution clearance. The documented public checks acquire, execute or install none of those archives.
