`Render(width)` is a raw Source comparison surface, containing ANSI and arbitrary background callback output. It must not be written directly to a terminal. Text preserves ECMAScript blank detection, three-space tabs, CRLF/CR/LF splitting, CJK token breaks, long-word grapheme wrapping, ANSI color/underline/OSC8 continuation, reduced narrow margins, callback ordering and cache invalidation. Padding callbacks run after content callbacks and their rows are reused above/below. Source's reentrant behavior is intentional: callbacks can replace the current callback or call SetText; the final cache key records the text after callbacks, even if the returned rows used earlier text. Explicit invalidation clears that cache. The caller supplies one UI owner; concurrent mutation and recursively calling Render from a callback are outside this profile.

TruncatedText keeps text before the first LF; a CR remains content. It retains Source's unreduced horizontal margins, default ASCII `...`, clipped narrow ellipsis, SGR reset placement and OSC8 close terminator. For widths above three, it measures independently segmented ANSI-separated spans until overflow; exhaustion returns the original string, including trailing ANSI. At widths one through three, Source's whole-string width shortcut is retained. Width and segmentation come from the existing pinned native TUI helpers; exhaustive Unicode/version equivalence still needs genuine differential qualification.

Native differences are explicit: render results are immutable arrays; widths are integer 1–512; padding is integer 0–256; input is valid UTF-16 with at most 65,536 code units; component output is capped at 4096 rows and 1,048,576 code units. Invalid padding throws ArgumentOutOfRangeException; other text/width/output limits use TerminalRenderException. Background callback outputs are validated before cache publication. These limits do not claim equivalence with arbitrary JavaScript constructor values or unbounded Source allocation.

For terminal output, `TerminalTextFrameFactory.Create(component, viewportRows, columns, limits)` escapes canonical control data before wrapping/truncation using the existing inert Source-span projection. Text retains logical CR/LF separators; TruncatedText's CR is escaped as row data. The frame path independently reads current text, omits arbitrary background callbacks and never reads or changes the raw render cache. It emits no ANSI authority from user strings. It clips whole graphemes and excessive component rows, fills the requested viewport with empty rows after content, hides the cursor and admits the complete VT write budget. Filling empty rows allows an unchanged-size renderer to clear formerly visible content. Source-wide clusters and TruncatedText margin overflow can remain in raw rows; bounded frames report clipping. This factory borrows no lease and performs no I/O. The host owns scrolling, rendering, focus and invalidation; theme/color fidelity is not qualified by the inert profile.
