## Registry contract

`TerminalKeybindings` accepts ordered definitions, an explicit `Func<string, string, bool>` raw-data matcher, and optional ordered user bindings. `TerminalKeybindingDefinitions.Tui` contains all 47 TUI definitions in Source order, including intentionally overlapping defaults and initially unbound actions. It excludes agent and platform-specific defaults.

`TerminalKeybindingValue` preserves scalar versus array configuration shape. Exact strings are compared using ordinal equality: there is no key-name or modifier canonicalization. Resolution removes duplicates while retaining the first occurrence. A null user value models Source `undefined` and restores the default; an empty array disables the action. Unknown user IDs remain in `GetUserBindings()` but cannot match, claim keys, or appear in resolved bindings. Unknown definition lookup returns null and unknown key lookup returns an empty array.

`SetUserBindings()` replaces the entire configuration. Omitted earlier overrides disappear. Conflicts include only keys explicitly claimed by at least two known user IDs; default overlaps do not create conflicts. Conflict keys follow first user-key occurrence order and claimant IDs follow user-entry order. Both conflicting bindings continue to match. The consumer determines dispatch precedence.

`GetKeys()` and `GetConflicts()` return independent arrays. Resolved bindings follow definition order and collapse a single resolved key to a scalar while returning zero/multiple keys as arrays. `Matches()` tests configured keys in order and stops at the first success; unknown and disabled actions do not call the matcher.

Native adaptations are explicit: values and definitions are immutable snapshots; returned user/resolved dictionaries are independent maps. Source retains configuration references and exposes shallow array aliases through its user map. Mutating those aliases is not supported by this C# API; use `SetUserBindings()` for changes. Duplicate IDs in an enumerable input are rejected because Source objects already have unique property names; a failed replacement leaves the prior state intact. Numeric JavaScript property enumeration, prototype properties and declaration merging are not emulated. Pass definitions and configuration in the desired Source order. The registry belongs to one UI owner; no global registry or concurrent mutation contract is introduced.

## Startup loading and bounded adaptations

`LoadDefault()` snapshots only `PI_CODING_AGENT_DIR`, `WSL_DISTRO_NAME` and `WSL_INTEROP`, derives the home directory, and reads `<agentDir>/keybindings.json`. The default agent directory is `~/.pi/agent`; an explicit environment directory preserves whitespace and supports tilde, Windows shell-drive paths and basic file URLs. No models, authentication or other settings file is opened, and no setting is written. Missing/unreadable/malformed data selects defaults. Exactly one leading UTF-8 BOM is stripped. Source object/array roots are admitted; JSON null, mixed arrays and other invalid values are filtered. Empty arrays disable actions. Modern own properties block a legacy value even when the modern value is invalid and subsequently filtered. Known entries follow definition order, extras sort using ordinal UTF-16 order, and canonical numeric property names enumerate before other keys. Duplicate JSON properties retain their last value.

The 47 original TUI definitions remain byte-identical. Agent composition makes the Source undo and alternate-screen platform replacements and appends its 43 definitions, yielding 90. Windows and Linux with nonempty WSL indicators use the corresponding defaults; macOS preserves its tree alternative order. Defining these actions does not implement their UI contexts. `Reload()` rereads the same captured path and platform, drops omitted earlier overrides, and returns a new owner configuration. Earlier configuration and registry instances remain unchanged. Source mutates its manager in place; C# returns a replacement to preserve reader/producer snapshot consistency.

Native bounds are 1,048,576 UTF-16 characters, 4,194,304 input bytes, depth 64, 1,024 distinct entries, 256 alternatives per binding, and 256 characters per binding ID or key. Exceeding a bound selects the complete default configuration. Source has no matching bounds. JSON parsing uses System.Text.Json, and file URL conversion uses System.Uri with encoded-separator rejection. Exotic URL/path cases, malformed UTF-8 normalization, lone-surrogate JSON strings and JavaScript prototype-property behavior require independent comparison; no parity is claimed for those cases. Registry null models internal Source undefined; loader JSON null is filtered rather than passed as a null override.

This is a bounded native admission profile. The translated raw matcher recognizes Source forms that the existing decoder may still reject as unknown, including some historical legacy sequences; unknown-event suppression is intentional and full legacy admission remains open. Native integers and Unicode scalar validation are narrower than JavaScript numeric parsing. Source environment checks are captured as booleans at decoder construction. Constructed events lack wire mode and use named fallback. These adaptations need independent comparison; the candidate makes no full raw-protocol claim.

R43 corrects independent R42 findings `R42-CONFIGURED-PRINTABLE-01` and `R42-CONFIGURED-CONTROL-02`. `GetPrintableText()` retains both the original printable string and an authoritative null result without applying fixed default bindings. A shifted control or functional field cannot fall back to its printable primary name; constructed/cloned events still use named fallback. The intended Ctrl+J layout control now explicitly disables the configured newline claim and uses CSI-u to avoid raw-LF compatibility. Separate guards retain the original newline conflict and raw-LF precedence. R42 source, review and failure predictions remain immutable. New matrix controls compare historical/configured paths for press/repeat, lock masks, shifted control/functional values, valid shifted text, pending jumps, clones and disabled bindings. They remain authored and unexecuted.
