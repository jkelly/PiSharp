# Native SelectList component

Original package: **P5-09 Build rendering and interaction**. This is a standalone selector milestone on the lead's allocated new paths. It does not complete P5-09, P5-08, P5-10, a phase gate, or CLI/menu/extension integration.

Authority: Pi v0.99.1, upstream commit `d86654abb8862e201933517d6f1fce9f88dd117f`, `packages/tui/src/components/select-list.ts`. Exact Source member bytes, SHA-256 and Git blobs, dependencies and archive identity are in the consumer's `fixtures/source-authority.json`. Source-derived code retains the upstream MIT notice in the new consumer directory.

`TerminalSelectList` takes immutable item records, a positive maximum visible count, and an owner-supplied `TerminalKeybindings`. `HandleInput(TerminalInputEvent)` matches the original decoded event through `TerminalInputDecoder.MatchesKey`, preserving captured wire/protocol identity. `HandleInput(string)` uses the owner's supplied raw matcher. The component reads the current registry; the host chooses snapshot or live replacement ownership.

Selection follows Source's exact action priority: up, down, confirm, cancel. Up/down wrap, notify even when a singleton remains selected, and retain Source's negative empty-list indices. Confirm has no item callback when selection is absent; cancel works with an empty list. Page-up/page-down are deliberately ignored by this component despite their registry definitions. Release events follow Source matching; the component does not add an editor-specific release guard.

Filtering uses case-insensitive **value prefix**, preserves order and duplicates, resets selection to zero, retains the press anchor and emits no selection-change notification. It does not search labels or use fuzzy matching. Empty labels fall back to values; whitespace labels remain labels. Invariant scalar casing includes dotted-I expansion and contextual final sigma handling. Unicode tables and case-ignorable classification still require exhaustive comparison against the pinned Node/ICU profile; this source milestone does not claim that qualification.

Mouse coordinates are component-local. Wheel magnitude contributes one signed step and clamps rather than wrapping. Hover, non-left buttons, releases and non-item rows do not select. Source does not test X inside this component. A press stores the selected item index so recentering does not move the subsequent click target. Filtering after a press retains that index; a later click can therefore leave selection outside the filtered array without submitting an item. Selection is committed before callbacks. Click rereads the current item after a reentrant selection-change callback; wheel's render flag reads the final callback-modified index. Exceptions propagate without rolling back committed selection or cleared click anchors.

`Render(columns)` returns immutable Source-style comparison rows, including the empty-ellipsis utility's generated reset bytes and OSC8 close bytes. These rows are never a terminal transport. The layout centers the visible range, uses all filtered items for primary column width, normalizes reversed column bounds, applies the Source width >40 / remaining width >10 description thresholds, and preserves the custom truncator's double call on description fallback. Description normalization replaces runs of CR/LF and uses ECMAScript whitespace trimming. The unused Source `selectedPrefix` transform is retained but never invoked. Callback result sizes and UTF-16 are validated before further processing. Render callbacks may change filtering: disappeared later rows are skipped as in Source. Callbacks that recursively invoke rendering can still recurse; they remain caller-owned synchronous code.

`TerminalSelectListFrameFactory.Create` is the native output boundary. It uses the existing Source grapheme/width helpers and `TerminalTextLayout.EscapeSourceSpan`. Item/custom callback/theme controls become inert display text before bounded layout. Tabs display as three spaces and Thai/Lao AM uses the established safe projection. Textual themes may alter rows; their ANSI is escaped. Source utility reset bytes are omitted from native display output. These safety changes can alter spacing and custom truncator input text, which contains the safe display projection while its `Item` retains canonical data. Native selection styling uses a private inverse span created from component state; public row strings cannot authorize it. Unfocused output retains selection text and omits native inverse styling.

The factory validates viewport, total rendered input, frame/encoded VT output and grapheme limits. It clips only at whole graphemes and never mutates canonical items or selection. On a window shorter than the Source component, it crops to retain the selected row and returns `ComponentRowOffset`. Translate frame-local pointer Y with `ToComponentPointer`; the host still supplies screen origin, capture, focus and event ownership. Re-render before dispatching through a stale frame after selection/filter/resize changes. Overwide Source no-match/prefix rows are retained by the comparison surface and explicitly clipped by the native frame.

The component and factory perform no I/O and own no terminal, task, environment, file or credential resource. A host can pass their `TerminalFrame` to the existing borrowed `VtRenderer`. Component `Invalidate` is a Source no-op; the host must also invalidate its renderer after resize or unrelated terminal output. CLI startup, keybinding definitions, focus/editor/paste controllers and the renderer itself are unchanged.

The separate TUI-only console consumer authors 31 component/renderer cases and one reporting-control plan unit containing six nested fault controls. It uses actual decoder/component/frame/VtRenderer APIs, fake terminal writes, original held-write joins, and borrowed-terminal disposal checks. Expectations are authored from Source inspection, **not executed Source captures**. No restore, build, consumer execution, Source execution, or physical-terminal observation was performed for this candidate.

Correction for independent review finding `SELECTLIST-ANSI-GRAPHEME-TRUNCATION-1`: canonical truncation measures each text span separated by recognized ANSI and tabs before deciding whether input overflowed. Whole-string `visibleWidth`, which strips ANSI and can join regional indicators or ZWJ sequences across that boundary, cannot authorize the truncation shortcut. Only printable ASCII uses the Source shortcut. An exhausted input without overflow returns original bytes, including trailing pending ANSI; an overflowing input drops pending ANSI before Source final reset/hyperlink closure. The exact reviewed `U+1F1FA + ESC[0m + U+1F1F8` / `Render(6)` regression, larger and unsplit budgets, fifteen joining/exhaustion controls, and a separate inert-native-frame/VT control are authored. Their expected bytes are static predictions pending unchanged Source and native execution. The safe-frame adapter and all previous expectations remain unchanged.
