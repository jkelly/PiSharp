# Registered before-tree cancellation classification

Cancellation is reported only when the operation is requested, session/extension lifetimes remain live, every failed recorded original is a canceled admitted callback with its exact linked token, and the full primary graph contains only those same directly observed cancellation exceptions. Faulted originals, unknown synchronous exceptions, empty aggregates, and foreign tokens remain faults. Actual context-disposal originals are joined before classification. No cancellation wrapper erases a cleanup sibling.

Three new controls use the actual registry and native captured session provider: held cleanup with genuine cancellation; canceled handler plus an actual UI cleanup fault; foreign-token cancellation. They retain first producer observations, raw Tasks, cached aggregate/direct references, and release/join held originals in finally. They are source-only, unregistered, and UNEXECUTED.
