# Actual summary transport cancellation contribution

This successor retains independently accepted recovery `9f665ca90eb68810642ea98c1e8c0d2020f2102e` and adds real Completions chunk-transport summary controls. The initial unchanged-production candidate `1c85ed5ae2b73e5240a4558fdd5513c837b5febb` reproduced two failures: requested cancellation surfaced as `SummaryFailed`, and the durable SDK reported its automatic compaction as failed instead of cancelled. Both genuine error/tool-call controls passed. All source and executed bytes from that run are preserved separately.

The production change admits only a matching `StreamError`/`Aborted` terminal when this actual caller token is already cancelled, then finishes the stream's awaited drain/disposal before the existing token check throws cancellation. Mismatched terminals, genuine provider errors and unrequested aborted terminals retain the failed-summary contract. The generator still owns no executor and cannot append a checkpoint. Physical cleanup exceptions are not caught or converted by this change.

The SDK control uses actual local JSONL storage and an actual `OpenAICompletionsWireSource` inside `TransportSessionSummaryGenerator`. It asserts persisted omission, retained billed usage, one provider attempt, one summary acquisition/cleanup, no compaction or hidden retry, ordered low-level end/recovery/final events, busy state during held cleanup and canonical reopen together. These are authored native conjunction controls, not a whole upstream AgentSession oracle.

Original P4-07 remains open for whole AgentSession request/event/queue ordering, pre-prompt versus post-run compaction, model/projection usage authority and configuration lifetime, complete queue/replacement and aggregate turn semantics, and required dependencies. After composing the newly reviewed typed carrier, separately qualify cancellation with secondary physical cleanup failure; the prior carrier cannot represent that secondary failure independently. All 79 original package scopes and eight full phase gates remain intact.
