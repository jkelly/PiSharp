# Reload original callback faults successor

This source-only successor preserves the frozen planner commit `80a193f5ec9787749c845af71efee18447a1bb07` and its evidence. Direct await observes only one exception from a faulted Task.WhenAll. Multicast Func callbacks invoke all targets but return only the last ValueTask. Neither pattern proves ownership of every returned operation.

The planner now rejects every multicast host callback before any callback runs. For each admitted asynchronous callback it captures ValueTask.AsTask exactly once, awaits that original task to completion, and reports a HostReloadCallbackFailure containing the original task's IsCanceled status and original Task.Exception reference. Task.WhenAll sibling exception objects therefore remain available through OriginalTaskException; a genuinely cancelled task has no Task.Exception and retains the caught cancellation exception separately. A faulted task whose fault is OperationCanceledException remains classified as faulted. Synchronously thrown callback exceptions keep their original identity. No cancellation wait wrappers or detached joins are introduced.

The planner owns this callback adaptation for its fourteen HostReloadOperations delegates, including candidate cleanup during staging and generation cleanup during workflow retirement. ResourceReloadWorkflow itself is unchanged and still has direct-await behavior when used independently with other ResourceReloadOperations callbacks. Startup ordering, authority and held original attempt joins remain unchanged. This successor is not automatic whole-reload acceptance. Reservation, actual invalidation/drain and atomic registry/session publication remain required host seams.

Four additional source controls cover held multi-fault staging, held multi-fault retirement, faulted OperationCanceledException versus original task cancellation, and multicast rejection across all callback slots before any invocation. Existing ten planner cases remain authored. Shared Program registration and all native execution remain reserved to the coordinator. No builds or tests were executed.
