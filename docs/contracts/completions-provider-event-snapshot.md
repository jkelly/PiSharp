# Provider event raw and JSON views

`CompletionsLifecycleHooks.OnProviderStreamEventSnapshot` is an awaited callback on the actual decoded provider event, before the Completions mapper admits it. Its `CompletionsSourceSnapshot.Raw` owns the event value and own-undefined presence data; `SerializedJson` is generated by the existing native ECMAScript projection. The snapshot may be retained after the invocation closes. Source and canonical transport paths use the same callback.

The raw view preserves numeric bits, including negative zero. The JSON view represents JSON.stringify of that value: negative zero serializes as `0`, with ECMAScript numeric rounding and property ordering. These are separate observations. Reading numeric bits from the serialized JSON loses the original negative-zero sign. No callback value is rewritten to satisfy a serialized-value comparison.

If both callbacks are configured, the existing `OnProviderStreamEvent` callback runs first with its unchanged raw JsonData, then the snapshot callback runs. Each is awaited; cancellation is checked between them and before mapping. A raw-hook fault or cancellation prevents the snapshot callback. A snapshot-hook fault retains the existing sanitized/public-failure policy and joins all owned cleanup. An unfinished callback remains owned by the invocation even after source semantic cancellation settles.

Exact DONE is checked before parsing or invoking either callback. Named API error frames and truthy error payloads fail before callbacks. Falsy error payloads and thread event/data envelopes follow the existing decoder path. Snapshot construction uses the invocation's existing MaximumSourceValueCharacters/MaximumSourceValueBytes limits, including its raw/presence envelope, and the bounded native projection; no extra HTTP/body read occurs.

This supplies the missing paired JSON observation for the two retained negative-zero hook spelling findings. The original strict comparator remains unchanged unless its real capture is separately coordinated to read the production JSON view and raw numeric view independently.
