# Anthropic Messages parsed stream mapper

The [approved provider differences](../compatibility/approved-provider-differences.md) record the narrow compatibility decisions for split CRLF, late cancellation data and sanitized errors. They do not waive qualification or establish full equivalence.

PiSharp.AI.Protocols.AnthropicMessages.AnthropicMessagesTransport is an actual offline IChatTransport over caller-supplied owned JsonData DTOs. It consumes an asynchronous parsed event source and produces native immutable StreamEvent values validated by the shared AssistantStreamReducer. It performs no HTTP request, credential lookup, SDK installation, clock read, tool execution or request projection. This is a dependency-ready portion of [P2-06](../plans/02-provider-layer.md); provider, protocol and phase acceptance remain open.

Source authority is the unchanged complete public [anthropic-messages.ts](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/api/anthropic-messages.ts), [provider wrapper](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/providers/anthropic.ts), [types.ts](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/types.ts) and [models.ts](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/models.ts), at public Pi v0.99.1 SHA d86654abb8862e201933517d6f1fce9f88dd117f. The complete pinned [SSE parsing tests](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/test/anthropic-sse-parsing.test.ts) and [one-hour cache pricing tests](https://github.com/earendil-works/pi/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/test/anthropic-cache-write-1h-cost.test.ts) inform the authored controls. These tests are native authored DTO scenarios, not recorded provider traffic or independently executed unchanged whole-helper reference captures.

The API is:

    new AnthropicMessagesTransport(sourceFactory, options)
    transport.StreamAsync(chatRequest, cancellationToken)

The request model must identify the anthropic-messages API and nonblank provider/model strings. Its timestamp supplies the native output timestamp; no time is generated. AnthropicMessagesOptions supplies positive event count, per-event and aggregate raw UTF-16 character limits, content slot and reducer character limits, a separate accumulated signature character limit, JSON depth from 1 through 64, and explicit nonnegative decimal AnthropicTokenRates. Rates are dollars per million tokens. Omitted rates mean zero cost; there is no inferred catalog or monetary assertion.

The source factory receives the original request and caller token once. Its returned asynchronous enumerator is acquired before native Start, which has empty content, zero usage and pending stop reason. A source acquisition failure produces a single bounded Error without Start. Events are pulled only when the native consumer requests more data. Early disposal, source exceptions, cancellation and normal exhaustion all await owned enumerator disposal. No Done or Error is emitted before that cleanup completes. Cleanup failure turns an otherwise complete stream into Error; an earlier source/protocol failure retains priority. Actual caller cancellation takes priority after cleanup, including cancellation during final cleanup. An unrelated OperationCanceledException from the source is SourceFailed, not caller cancellation. Pre-cancelled input throws with no factory call.

Known parsed events are message_start, content_block_start, content_block_delta, content_block_stop, message_delta, message_stop, error and ping. Native admission requires one message_start, distinct nonnegative Int32 wire block indices, correctly typed deltas to active blocks, single block ends, a recognized stop reason and message_stop. Sparse wire indices become contiguous native content positions in start order. Successful settlement requires every started block to end. A ping is bookkeeping, including after message_stop; other post-stop events, duplicate starts, unknown events, bad index/type combinations, unfinished successful content and unsupported blocks fail explicitly. The public source often ignores unmatched/unknown event shapes; stricter native structural admission is an explicit hardening difference.

Text and thinking starts retain initial content, including empty strings, and opaque block fields. Text and thinking deltas accumulate independently across interleaved blocks. Signature deltas append to private bounded thinking metadata without inventing a new normalized progress event. ThinkingEnded carries the authoritative complete thinkingSignature; final output and aborted/error output retain the accumulated signature. Earlier immutable ThinkingStarted events retain their original signature. The shared normalized contract does not expose Pi's mutable per-event partial object snapshots, so arbitrary partial-snapshot equivalence is not claimed.

Redacted thinking becomes the exact source text "[Reasoning redacted]" with thinkingSignature equal to source data and redacted true. Unknown block JSON fields, explicit nulls and opaque numeric tokens are preserved as owned inert JsonFields. Anthropic's helper does not author a tool namespace; any unknown wire namespace here is retained as inert metadata and receives no routing or extension authority.

Tool starts retain source ID, name and object input, defaulting absent/null input to an empty object. Incremental input_json_delta strings are preview scratch only. ToolCallEnded uses `parseStreamingJson(block.partialJson)` of the accumulated scratch (`StreamingJson.Parse`), as content_block_stop does upstream. Empty scratch produces an empty object, replacing any start input. Scratch is absent from final replayable tool content. Incomplete, repairable, duplicate-key and non-object arguments are kept as upstream returns them; a malformed final argument never fails the turn. No emitted object or metadata executes a delegate, restores a CLR type name or invokes a tool.

message_start response id becomes responseId. A response model different from the requested model becomes responseModel while requested model identity remains unchanged. Empty/null/absent response model means no override metadata. Initial usage missing/null fields default to zero. message_delta updates only present nonnull usage values, preserving omitted/null initial counts; explicit zero replaces earlier usage. Native count values must use nonnegative Int64 integer JSON tokens. Fractions, exponent tokens, strings, negative numbers and overflow are rejected rather than coerced into JavaScript numbers. Unknown opaque numeric JSON remains unconverted.

The mapper captures input, output, cacheRead, cacheWrite, nested cache_creation.ephemeral_1h_input_tokens as cacheWrite1h, and delta-only output_tokens_details.thinking_tokens as reasoning. Reasoning is a subset of output and is not added again to totalTokens. totalTokens is the checked sum of input, output, cacheRead and cacheWrite. Native admission requires one-hour cache write not to exceed all cache write and reasoning not to exceed output. Cost uses supplied base rates; one-hour cache write uses twice the input rate, and remaining cache write uses the cache-write rate. Checked decimal arithmetic and checked totals reject overflow. Permitted server fallback costs use explicitly supplied AnthropicFallbackModel profiles. At message_start, a nonempty returned model different from the requested model selects the first exact provider/model profile for the requested provider; absent, unknown, differently cased or foreign-provider models keep requested rates. Zero fallback rates are valid. The selected rates apply before initial usage and remain authoritative for later usage and failure settlement, including one-hour cache writes. Requested identity remains unchanged. Profiles have distinct provider/model identities, well-formed Unicode, nonnegative rates and a count bounded by MaximumContentSlots. Catalog resolution and pricing tiers remain outside this mapper.

Stop reasons end_turn, pause_turn and stop_sequence map to Stop; max_tokens maps to Length; tool_use maps to ToolUse. refusal and sensitive return Error while retaining rawStopReason and reported usage. Refusal explanation is actual provider output retained in errorMessage, with the exact source default "The model refused to complete the request" when absent/empty; sensitive uses "Provider stopped with: sensitive". Unknown stop reasons fail explicitly while retaining their raw string. Missing message_start, message_stop or a stop reason returns UnexpectedEof. Source/error payloads and parser/cleanup exception messages are not copied into diagnostics.

Failures produce a sanitized StreamError and fixed anthropicFailure enum string in message metadata: SourceFailed, MalformedStream, UnexpectedEof, ResourceLimit, ProviderError, Cancelled or CleanupFailed. Cancelled uses Aborted; all others use Error. Other than the documented refusal explanation, errorMessage is fixed and payload-free. This mirrors the source wrapper's error terminal shape. The existing ChatRun maps an admitted StreamError to Provider or Cancelled; anthropicFailure remains available to distinguish adapter categories. A thrown shared reducer or terminal-envelope budget failure is classified by ChatRun's existing exception taxonomy. No shared reducer policy has been changed for this slice.

Every DTO is strictly reparsed from its raw owned JSON before mapping, rejecting trailing commas or interior comments introduced through permissive caller JsonDocument settings. Decoded strings and property names require well-formed UTF-16. JSON depth and all raw DTO characters, including ignored/opaque fields and ping data, are bounded. Accumulated signatures have their own bound even though they emit no progress. The private reducer charges normalized envelope, content, argument preview, opaque metadata and final/error terminal fields. A second ChatRun reducer can impose lower caller limits. These are logical parsed-input/normalized-output bounds, not a UTF-8 network byte cap or total heap limit; the caller already owns its DTO and request data.

Pre-output fallback content_block_start markers produce no assistant content or progress event. Optional marker stops also produce no progress. Marker from/to metadata does not select pricing; message_start.model is authoritative. Distinct nonnegative marker indices are retained separately from contiguous native content positions and bounded by MaximumContentSlots; raw event limits still apply. A fallback after any actual content starts fails explicitly while retaining prior content. Duplicate marker starts/stops, index reuse and deltas to marker indices retain native strict structural rejection. Markers need no stop for successful settlement, matching source bookkeeping. Nonempty input_transformations still fail explicitly. Binding diagnostic authoring, OAuth tool-name canonicalization, dynamic tools, image and thinking replay, static request schemas, cross-model transcript transformation and full HTTP/SSE composition remain required work under the plan. They are not permanent exclusions or silent field drops. No request projector or temporary fake request object is provided by this frozen mapper slice.

Eight authored test groups cover sparse/interleaved text/thinking/tool operations and decimal costs; authoritative signatures, redaction, Unicode and immutable ownership; strict final tool arguments and empty scratch; missing/null/zero usage and number profiles; known stops, refusal details, malformed protocol and EOF; inclusive raw/depth/signature/slot bounds and strict permissive-element rejection; awaited normal/early/fault cleanup with foreign cancellation; and actual caller cancellation plus shared ChatRun budgets and abort settlement. Root owns registration, isolated execution, immutable review and genuine reference preparation. No paid provider request, SDK dependency or credential access is used.
