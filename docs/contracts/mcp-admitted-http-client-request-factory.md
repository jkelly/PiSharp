# Caller-admitted HttpClient request factory

`PiSharp.Cli.Mcp.AdmittedHttpClientRequestFactory.Create(HttpClient borrowedClient)` returns `McpAdmittedHttpRequestFactory`. Factory invocation allocates a fresh affine operation and has no HTTP effects. It never constructs/disposes a client, changes supplied headers, reads credentials, or acquires network authority.

SendAsync invokes the supplied client's actual SendAsync with ResponseHeadersRead and a request-specific cancellation source. Caller cancellation links through a non-awaiting registration which starts the same stable StopAsync original. Stop cancels only that source, captures CancelAsync before awaiting, waits for send admission to finish, directly joins the actual HttpClient header task and its send wrapper, joins cancellation callbacks, then disposes only its registration/source. This admission fence handles caller cancellation occurring synchronously inside handler initiation and cancellation racing callback registration. Stop before send fences effects; send is affine. Header failures belong to SendAsync; Stop joins without rethrowing them again, while original cancellation/cleanup faults remain on stable repeated Stop. Late headers transfer to the transport; request/response/body disposal remains with that owner. Header/handler callback context rejects lifecycle self-wait before mutation.

HttpClient abort is cooperative with its supplied handler/framework. This leaf requests actual per-request cancellation and joins actual originals; it cannot force an arbitrary handler which ignores cancellation to terminate. Such an admitted handler must remain held until its true original settles. The host must qualify its actual handler's physical abort behavior before native use. It must never substitute global-client disposal or a completed/no-op stop. No loopback/native/framework execution qualification is claimed.
