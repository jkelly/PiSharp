`WindowsConsoleTerminal.OpenAsync(options, token)` acquires this process's standard console. `OpenBorrowedHandlesAsync(SafeFileHandle input, SafeFileHandle output, options, token)` instead accepts explicit borrowed handles. Both return `ValueTask<WindowsConsoleTerminal>` and reject non-Windows, invalid/disposed/non-console handles, invalid bounds, cancellation before acquisition, and a concurrent process lease. Console input is checked through `GetConsoleMode` and `GetNumberOfConsoleInputEvents`; output requires console mode, cursor and screen-buffer inspection. The caller must own a genuine console profile with one input consumer and one state owner. Other processes or handle aliases changing or reading the same console are outside the exclusive-lease guarantee.

Acquisition duplicates each borrowed handle under its safe-handle lifetime guard. The lease owns and closes only the noninheritable duplicates. It captures input/output modes, both code pages, cursor visibility/size, and cursor position before any mutation. Input temporarily disables processed/line/echo/QuickEdit and enables extended/VT input; output enables processed/VT output; the cursor is temporarily hidden. There are no code-page, environment, standard-handle, console-attachment, control-handler or system-setting changes. `ReadConsoleW` and `WriteConsoleW` carry UTF-16 directly. Output is a trusted terminal-transport frame, not a sanitizer or data renderer.

The default read chunk is at most 4,096 UTF-16 code units (configured range 1..65,536). The default write frame is at most 65,536 code units (configured range 1..1,048,576). One read and one write may be admitted concurrently; a second read or second write is rejected. Writes copy the admitted frame, validate complete UTF-16, and make at most 4,096-unit native calls without deliberately splitting surrogate pairs. Returned native read characters survive cancellation that arrives at completion. Concurrently mutating a caller read buffer remains a caller error.

Each admitted operation retains a dedicated synchronous worker and a duplicate of that actual worker's native thread handle. Caller cancellation or lease closing repeatedly calls `CancelSynchronousIo` until the worker settles. The retry addresses `ERROR_NOT_FOUND` when cancellation lands before the native call begins. It does not abandon a `ReadAsync` behind `WaitAsync`, free a live destination, restore modes while a native worker remains, or close a duplicate to simulate successful cancellation. Caller cancellation reports its original token; closing-triggered cancellation reports `ObjectDisposedException`. Some native environments may refuse interruption; the operation remains owned until settlement rather than claiming safe cleanup. The external gate must retain its process watchdog for that unsupported case.

Concurrent `DisposeAsync` calls share one completion. Disposal closes admission, requests cancellation, awaits retained input/output work, attempts every original mode/cursor/position restoration, independently inspects real state, and only then releases handles and the process reservation. Failed acquisition after mutation also attempts and verifies exact restoration. A restoration failure is a fixed typed `TerminalException`, not success. The snapshot distinguishes the captured original/acquired/restored states, closing, confirmation, active operations and admitted/settled worker counts. Counts include operations canceled before a native call; they do not certify an actual blocked call.

`PiSharp.Tui.Input.TerminalInputDecoder(options = null, timeProvider = null)` is a separate single-consumer, terminal-independent decoder. `Feed(ReadOnlySpan<char>)`, `FlushTimeouts()` and `Complete()` return `ImmutableArray<TerminalInputEvent>`. The host supplies raw console chunks and schedules timeout polling; this decoder creates no timers, input readers or background tasks. It uses the injected `TimeProvider` monotonic timestamp, making exact timeout tests deterministic.

The supported typed events are text, key with modifiers/action, bracketed paste, recognized protocol traffic, and unknown sequences preserved as data. The initial key profile includes C0/DEL controls, Alt text/scalars, CSI/SS3 arrows/Home/End/F1..F4, CSI Shift-Tab, tilde Home/End/Insert/Delete/PageUp/PageDown/F1..F12 and xterm modifiers 1..16. The declared Kitty subset accepts a single Unicode scalar or listed navigation/F1..F12 private-use key, modifiers 1..16, and optional press/repeat/release (`CSI code;modifier:event u`). Alternate-key lists, associated text, larger modifier masks and other forms remain unknown sequences. Focus reports, CSI cursor-position/device-attribute replies and terminated OSC/DCS are protocol data. Nothing in these events authorizes replaying a control sequence to output.

UTF-16 surrogate pairs survive read fragmentation; invalid lone surrogates fail and close the decoder. Ordinary text can be split into adjacent events by chunk boundaries. Bracketed paste begins at `ESC[200~`, ends only at the exact `ESC[201~`, and preserves embedded newlines, controls, escape fragments and nested opening delimiters literally. Paste payload defaults to 65,536 code units (range 1..1,048,576); sequence storage defaults to 4,096 (range 6..65,536); an input chunk defaults to 4,096 (range 1..65,536). The terminator candidate retains at most six extra code units. Exceeding a bound fails and closes the decoder without returning that feed's partial events.

A lone Escape expires after 35 ms by default; other incomplete sequences expire after 250 ms. Positive configured Escape must be no larger than sequence timeout, and sequence timeout is at most one minute. Timeout emits Escape or the preserved unknown fragment. Paste is bounded by payload size and waits for its explicit terminator; sequence timeout does not truncate paste. `Complete()` emits a final Escape/unknown fragment, rejects incomplete UTF-16 or unfinished paste, and closes admission. Closed decoders reject reuse. This is a bounded parser profile, not full keyboard-protocol or upstream parity.
