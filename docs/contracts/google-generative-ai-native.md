# Native Google Generative AI direct key-auth milestone

This implementation adds standalone direct Google Generative AI streaming on the R47 allocation's exact base. It borrows an explicitly supplied HttpClient, reads caller-owned complete frozen model metadata and accepts an explicit API key. It makes no credential/environment reads or live calls during development.

The reference is Pi v0.99.1 commit d86654abb8862e201933517d6f1fce9f88dd117f: [provider](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/providers/google.ts), [stream implementation](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/api/google-generative-ai.ts), [shared conversion](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/api/google-shared.ts), [history transform](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/api/transform-messages.ts), [strict tools](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/api/constrained-sampling.ts) and [transcript replay](https://github.com/badlogic/pi-mono/blob/d86654abb8862e201933517d6f1fce9f88dd117f/packages/ai/src/utils/transcript.ts). Context resolution follows utils/estimate.ts: UTF16 text length divided by four and rounded up, 4800 estimated characters per image, system sections and serialized tool deltas, thinking/text/tool-call argument characters, and the latest applicable positive assistant usage with trailing estimates. A newer prefix timestamp prevents an older assistant usage from replacing the applicable anchor; aborted/error usage is excluded. Zero totalTokens falls back to input/output/cacheRead/cacheWrite. The response ceiling uses the supplied cap or model maxTokens, then the context window minus the estimate and 4096 safety tokens with a one-token available-room floor. For a nonpositive context window the supplied/model ceiling has a one-token floor. Finite fractional and negative explicit caps retain Source behavior for positive context windows. Rejected attempts join their original body release, response and request before backoff or the next attempt. Failing release prevents retry and preserves the provider primary plus a separate cleanup diagnostic. Cancellation joins admitted original operations, cancels backoff and prevents later attempts. RetryTimeProvider, RetryJitterSample and OnRetry are native seams outside SDK parameters and Pi wire JSON. Generic callback/send/acquisition failures and faults after successful stream acquisition are not retried.
