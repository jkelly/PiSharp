# Explicit admitted Anthropic profile caller

`OfflineSessionProfile.CreateAsync` appends optional resolved authentication and a borrowed HTTP handler after all existing parameters. The existing key lookup and handler factory run unchanged when no explicit resolution is supplied. Resolved admission rejects missing/foreign authentication, handler-only composition and cancellation before profile filesystem or HTTP effects. This does not introduce automatic credential acquisition or change ordinary CLI command argument parsing.

The actual profile registry main transport and its actual summary generator now use the existing resolved Anthropic connection. Main output stays at the selected cap; each summary acquires its own lease with its requested cap, thinking off and cache retention none. The handler remains caller-owned. Profile disposal awaits the actual connection close; exact original connection admission/cleanup aggregate faults are retained. A small existing-frame guard is checked before profile disposal installs any settlement or closes Sessions. Active callback self-close is refused; inherited inactive descendants may close afterward.

Six authored, unexecuted groups call the genuine profile factory: three admitted authentication channels through main and two summaries; unchanged legacy key route; four zero-effect admission refusals; held main and summary HTTP originals with profile close joining; active self-close refusal followed by another main request and inactive inherited descendant close. The tests inspect real synthetic HTTP bytes and directly join actual profile/drain/summary/send/close Tasks. Summary cancellation propagates after its actual aborted stream drains; direct main cancellation yields an Aborted terminal and may complete normally, matching the existing transport contract. Full original aggregate/direct fault references survive test and report cleanup.
