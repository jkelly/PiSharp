# Callback context and native session facade

Source-only bounded successor of a9df14f95d530157de021da81bc9fd17f69e2fd0. No build, tests or qualification have run for this delta.

The pinned Pi 0.99.1 ExtensionContext exports live cwd/model/idle/pending-message/system-prompt getters. The accepted native context supplies ownership and captured session state, but does not expose those live host reads. ExtensionCommandFacade.CreateCommand composes an ordinary native command descriptor with explicit IExtensionContextReadHost dependencies. Native registry admission, callback frames, cancellation and close/quiescence drainage remain the owners. No new session engine or host mutation authority is introduced.

Reads check the exact originating facade callback lease and all three native context tokens before and after invoking the host getter. Host getters run outside the facade gate. SessionId, LeafId and GetBranch read the captured native branch; they are not a full ReadonlySessionManager graph. Fresh session results receive the actual broker-returned context with its new session generation and tokens.

NewSession, ForkBefore/ForkAt and SwitchSession map to existing optional native command broker interfaces. Unsupported host contexts fail before any host action. Null canceled results remain null. The actual ValueTask is invoked and converted once. Its original Task and mapped result task are both retained and directly awaited before the adapted native command returns, even if a caller ignores its result. A held operation therefore extends the existing native admission. Multi-fault originals retain their complete AggregateException graph and exception objects; callback and joined-action failures are combined without replacing original nodes. There are no timeout wrappers or detached task observers.

The callback lease fences further facade operations when the user callback returns, while admitted actions settle. Returned facades share that originating lease. A retained facade cannot authorize a later callback. Awaiting mapped actions may commit a session before a postcommit native admission failure; existing native committed receipts are propagated, not rewritten as cancellation.

Original waitForIdle/reload/abort/shutdown/trust/UI/scopedModels/thinkingLevel/contextUsage/full session graph/newSession setup/withSession/navigation/compact are outside this delta. In particular, compact's original void trigger has no admitted native action owner here. Fork selected text remains available in the underlying native result but is not exposed by this bounded facade. The new API is an explicit native adapter, not a claim of complete JS ABI parity.

Twelve controls are authored in ContextSessionFacadeTests.cs: the original eight plus callback multi/shared-leaf graph, callback faulted-OCE versus canceled original, action faulted-OCE versus canceled original, and two ignored differently-token canceled actions combined with a third canceled callback original. The shared test runner is unchanged; these controls require a separately authorized harness before execution.

The R670 successor materializes the actual callback ValueTask exactly once as a Task and joins that original before joining actions. Callback multi-fault graphs retain all original branches and repeated shared exception references. A faulted original whose await-selected exception is an OperationCanceledException is reported through the non-OCE ExtensionFacadeOriginalFaultException. It retains the exact OriginalTask and its complete OriginalException graph. This explicit native adaptation preserves Faulted status rather than allowing the async adapter to misclassify the fault as cancellation. The returned mapped action also uses this envelope. A genuinely canceled original remains canceled with its original cancellation token; a single canceled original remains cancellation. Multiple canceled originals produce a Faulted AggregateException outcome that preserves every cancellation node instead of selecting one token. Each ExtensionFacadeCanceledOriginalException retains the exact canceled OriginalTask, its original await exception as InnerException, and the exact CancellationToken. Mixed failures and cancellation likewise retain all nodes in a fault aggregate. This is an explicit native combined-outcome adaptation, including when a callback and an awaited action each produce distinct canceled originals. Synchronously thrown callback OCE before a returned original is a fault with its exception reference retained as InnerException. No shared host await policy is changed.
