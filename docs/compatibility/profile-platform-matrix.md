# Profile and platform decision matrix

Reviewable P1-04 draft, dated 30 September 2026. The target is public Pi v0.99.1 at `d86654abb8862e201933517d6f1fce9f88dd117f`. The implementation evidence snapshot is the bounded accepted native candidate `bb9e905757724a4880e2bea3269207fd77597f47`; subsequent reference/tooling work does not expand that native acceptance. P1-04 closure remains assigned to parent/product in [implementation-status.json](../../compatibility/implementation-status.json).

The [architecture](../architecture.md), [eight plans](../plans/README.md), [surface inventory](../../compatibility/surfaces.json), [parity rows](../../compatibility/parity.json) and existing [native-v1 profile](../../compatibility/profiles/native-v1.json) supply the requirements. The inventory is explicitly a seed: 45 mandatory families and one optional bridge family, all Deferred. Detailed commands, provider capabilities, events, SDK operations and platform conditions must still expand those families. This draft preserves their mandatory status and introduces no additional scope exclusions.

PiSharp's native product remains **C# / .NET 10 with a JIT host, a first-class native C# extension SDK and a Node-free installation/runtime**. The optional TypeScript bridge has a separate package, runtime matrix and acceptance gate. Required MCP/codemode behavior stays in the native requirements even where its implementation needs a non-Node JavaScript execution component. Completing the full eight-phase work includes the optional bridge workstream; qualifying the native release follows the plans' separate native and bridge gates.

## Proposed OS and architecture matrix

Windows x64, Linux x64 and macOS arm64 are already the architecture, P5-10 and P8-03 initial targets. Linux arm64 and macOS x64 are already staged expansion targets. The concrete test floors below are proposed so qualification can be scheduled; release owners still need to finalize versions and terminal coverage.

The official [.NET 10 support table](https://raw.githubusercontent.com/dotnet/core/main/release-notes/10.0/supported-os.md), checked 30 September 2026 and marked updated 28 September, supports the proposed Windows 11 24H2, Ubuntu 22.04 and macOS 15 floors and their listed architectures. Runtime support is necessary; PiSharp's filesystem, terminal, plugin/native-library and installation tests determine its advertised support.
