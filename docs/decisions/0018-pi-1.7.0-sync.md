# Pi and Pi Durable 1.7.0 source update

Pi and Pi Durable share the upstream tag [v1.7.0](https://github.com/earendil-works/pi/tree/fb0fe823539f6d04850f6e34748c01f01f212e1f). The update includes changes from the intervening 1.6.1 release. The candidate is based on PiSharp 1.6.0.2 and retains its Apple Silicon terminal-size fix.

The [source inventory](../../compatibility/sync-1.7.0-files.json) records all 1,683 changed files from the two Git trees. The [candidate lock](../../compatibility/target.lock.json) pins the upstream commit, tree, source archive and file hashes. The [previous lock](../../compatibility/target.v1.6.0.lock.json) retains the source behind the 1.6.0.x releases.

The model catalog embeds the 43 provider shards from the published pi-ai 1.7.0 npm archive. It includes 1,701 chat models, 74 image models and 83 classifiers. Radius can also discover image and decision models from its configured endpoint. Its static npm shard contains chat models only.

Pi Durable consumes Chord storage, delta and watch APIs. The update ports the changes it uses, including filesystem sync durability, query argument validation, incremental array diffs and recovery after follow errors. PiSharp's separately published experimental Chord networking library continues to use its existing v1 peer protocol. Applications requiring interoperability with upstream Chord v2 need a separate migration of the wire format, grants and host dispatch.

Verification on macOS arm64 used the repository's .NET 10.0.401 SDK, an isolated offline terminal session, the tagged upstream source, the official npm archives and scripted provider responses. The Durable suite passed 4,866 cases with two platform or interoperability skips. Its real-host Chord integration passed all seven cases, and the Chord suite passed all 1,524 cases. Native Windows console event delivery and real provider accounts require separate verification.

This source update is an unreleased candidate. Historical test evidence and previously published release records apply to their original versions.
