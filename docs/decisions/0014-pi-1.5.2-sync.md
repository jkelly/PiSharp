## Target and scope

The candidate moves from Pi v1.5.0 (`f9a26365568127461c47a07a37dcb42c140a3ac5`) to v1.5.2 (`b4afdddf44e059c67ccf5097e5317d913521b470`). All packages and root changes are inventoried from the complete local Git diff in `compatibility/sync-1.5.2-files.json`; the inventory records both endpoints and hashes without an API file-count limit. Native runtime changes require implementation and regression evidence. Browser-only, upstream packaging and TypeScript-only changes need explicit applicability decisions. No inventory or version update establishes parity by itself.

The candidate package version is 1.5.2. The extension Node runtime installs exact 1.5.2 Pi dependencies into a version-isolated cache. Existing caches remain available. The detailed provider identity follows the candidate version; default attribution and account-selection policies do not change.

Source citation analysis is report-only; an area owner moves changed citations with its verified implementation. Existing acceptance gaps carry forward until supported by new evidence.
