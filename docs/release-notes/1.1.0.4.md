# PiSharp 1.1.0.4

A C#-only patch on the Pi **v1.1.0** baseline (commit
`abe508e1b89912adde45528136c3221eb69acdd7`).

The [Parity](https://pisharp.ai/parity/) page lists what still differs from Pi.

## Fixed

- **Startup header.** The interactive header showed Pi's package version (`v1.1.0`) next
  to the logo, and the onboarding line named Pi. It now reads **PiSharp v1.1.0.4**, using
  PiSharp's own product version, and the onboarding line names PiSharp. This is listed as
  an intentional difference from Pi.

## Packages

All library packages and the `PiSharp.Cli` dotnet tool are published as 1.1.0.4:

```powershell
dotnet tool update -g PiSharp.Cli
```
