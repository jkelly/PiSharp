# PiSharp 1.6.0.2

Released November 27, 2026. This patch fixes a crash when opening the interactive CLI on Apple Silicon. Both fullscreen and regular mode could fail while reading the terminal dimensions. PiSharp now gets the window size through .NET on macOS. [Fix and verification in PR #76](https://github.com/jkelly/PiSharp/pull/76)

Upgrade an existing global installation and check the version with:

```sh
dotnet tool update --global PiSharp.Cli --version 1.6.0.2
pisharp --version
```

The release tracks Pi and Pi Durable 1.6.0. The tag points to `fce4394aa5ea58d2bf933930d0ff1149fe5519aa`. The release workflow succeeded, GitHub published 31 package assets, and all 31 appeared on NuGet. A fresh CLI installation from NuGet opened the prompt on macOS arm64 and exited cleanly with Ctrl+D.
