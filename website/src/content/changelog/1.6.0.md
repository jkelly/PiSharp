**UNRELEASED:** Source candidate targeting Pi v1.6.0. See the [candidate notes](https://github.com/jkelly/PiSharp/blob/main/docs/release-notes/1.6.0.md) and [complete source applicability map](https://github.com/jkelly/PiSharp/blob/main/compatibility/sync-1.6.0-applicability.json) for validation status and limitations. This entry does not announce a release; the latest published version remains **1.5.2**.

### Changes by area

- **Models:** the complete exact Pi 1.6.0 catalog: 43 providers and 1,853 entries (1,698 chat, 74 image, 81 classifier), with 129 additions, 49 removals and 651 changes. It adds GPT-6.2 Astra and GPT-6.2 Sol. The four Qwen Token Plan providers use the current gateways, the Team names and a key variable per plan.
- **Providers:** retries for socket error codes, closed connections and the Codex 60-minute connection limit; strict tool schemas only where they are safe (untyped schema nodes, Mistral, GitHub Copilot); the Codex request shape of Pi 1.6.0; `openai_input_transformations` diagnostics; Anthropic message threads by endpoint; a Google `CONTINUATION` finish ends the turn as `length`.
- **Tools and exports:** `find` path patterns anchored at the search directory, `read` image and cancellation fixes, the end of an over-long last line of `bash` output, `pi.exec` exit codes for commands ended by a signal, and clickable terminal hyperlinks in the HTML export.
- **CLI sessions:** problems found at startup and when a session is replaced are reported once, in every mode; package installs no longer draw over the terminal UI; MCP tools loaded by `tool_search` survive resume and `/reload`; `/copy` and RPC `get_last_assistant_text` skip aborted and failed replies; a tool batch interrupted by Esc gets an `Operation aborted` result for every call.
- **Terminal UI:** read-only render output that containers reuse across frames, fullscreen scrolling that reuses earlier frames, a suspend handler for `SIGTSTP`, image fixes for overlays, Kitty redraws and Markdown, search fixes in the selectors, and a transcript notice when OpenAI drops reasoning items.
- **Durable:** signals, sleeps that wait for signals, tools that park, gates in `beforeTool`, hooks that start tasks, code-mode namespaces declared by extensions, image fitting, and examples 38 to 47.
- **Chord:** event members, call windows by trust, shared holds, column sets, named queries, lists, a commit that re-runs a live query only when it can change it, the app kit's sign-ins, client and sync fixes, and delete host data by plugin.
- **Chord admission and workers:** admission for remote contracts and routes with the `denied` failure cause, and the workers component's `Store`, `Admit`, `Incarnation`, exit ordering and `TerminalScope.On`. <!-- sync-1.6.0: confirm against the chord-admission / chord-workers report -->
- **Env, MCP and agent:** remote directory listings leave out vanished entries, the daemon keeps reading a program's output after exit while the link is backed up, and `McpCatalogPlanner.ServerSummary` gives a server's one-line summary.
- **Node extensions:** exact Pi 1.6.0 runtime packages in a version-isolated cache with `undici` 8.12.4, and fallback modules regenerated from the pinned source. Earlier caches, locks and release evidence are preserved.

### Breaking changes for C# users

- **`PiSharp.Tui`:** `IComponent.Render` returns `IReadOnlyList<string>`. Change the return type of every component, and copy render output before you change it: a `Container` returns the same list while its children are unchanged. `ITui` gains `SetSuspendSignalHandler(Action?)`, so an `ITui` implementation of your own must add it. `LayoutFrame` gains the positional member `RenderCache`, `LayoutBox.Lines` and `LayoutBox.ScrollContentLines` are `IReadOnlyList<string>`, and `TuiBase.ResolveFakeCursors` takes one.
- **Durable hooks:** `RunEndTask` and `Define.RunEndTask` are renamed `HookTask` and `Define.HookTask`, with no alias. `GenerationHooks.AfterTools` returns `Task<IReadOnlyList<HookTask>?>` and `GenerationHooks.OnYield` returns `Task<OnYieldResult?>`.
- **Durable tasks:** `SleepingTaskState.Until` and `TaskGraphState.Until` are nullable, because a sleep may wait for signals only. `Now()` is declared on `IHookApi`; `ITaskRuntime` inherits it. `Inbox.WithdrawQueuedInputsAsync` has no default reason. `IToolExecutionApi`, `IHookApi`, `ITx` and `IHarness` gain members.
- **Durable code mode:** `CodemodeNamespace` and `CodemodeToolOptions.Namespaces` are removed. Declare `Extension.Namespace` on the extension that brings the tools.
- **Durable storage:** `pi.tool` is version 4 and `pi.generation` version 3. A database written by 1.6.0 is not meant to be opened by PiSharp 1.5.2.
- **Chord app kit:** `Sessions` is renamed `SignIns`, with `EphemeralSignIns`, `SignInKind`, `SignInInfo` and `IssuedSignIn`. The cookie, contract and stored document names changed with it and there is no migration: everyone signs in again and paired devices pair again.
- **Chord options:** `TelemetryIngestOptions.Admit` is required. `ChordHttpOptions.LinksOpened` takes a third argument that closes the link. `HostError.Table` is `HostError.Query`. `IStore` gains `OnCommitted`. `Client.StartAsync` completes before the server's first script set is applied. `UploadOptions.Store` is an `ISessionSyncUploader`.
- **Chord wire:** the protocol version stays 1, but 1.5.x and 1.6.0 hosts do not interoperate over trusted links (workers and host-to-host routes), and a 1.5.x sync client refuses a remote that holds an archive slot written by 1.6.0. Update hosts and devices that share a link or a remote together.
- **Chord workers:** the workers component requires the server host's store (`ProcessWorkerOptions.Store`). <!-- sync-1.6.0: confirm against the chord-admission / chord-workers report -->
- **`PiSharp.Tools`:** `read` no longer adds a note for a model without image input. It names the model in `details.imageUnsupportedByModel`; `ReadWriteTools.NonVisionImageNote` is obsolete.

### Behavior changes

- The default model for `openai`, `azure` and `openai-codex` is `gpt-6.2-sol`.
- A `find` path pattern is relative to the search directory: `src/*.ts` finds `src/a.ts` and no longer `pkg/src/a.ts`. Use `**/src/*.ts` to match at any depth.
- `pi.exec` reports 128 plus the signal number for a command ended by a signal, not 0. For C# extensions, a command stopped by a timeout, an abort or the output cap reads 143 on Windows, where it read 1, and 137 on Linux and macOS, where Pi reads 143. TypeScript extensions report what Pi reports.
- The llama.cpp extension connects to `http://127.0.0.1:9931` by default, not port 8080.
- The PiSharp-only ceiling of 1,000,000 output tokens is lifted, so models whose catalog limit is higher can be requested.
- `Could not restore model ...` and other problems found when a session starts or is replaced are written to stderr in print, JSON and RPC modes.
- Reasoning models on OpenAI-compatible hosts other than `api.openai.com` receive the system prompt with the `system` role.
- Mistral models receive strict tools only when `compat.supportsStrictMode` is set.
- The shared `QWEN_TOKEN_PLAN_API_KEY` and `QWEN_TOKEN_PLAN_CN_API_KEY` still work; each plan's own variable is read first.

Source changes do not establish complete upstream or all-platform parity. Most work packages ran on Windows only. Browser DOM and React, upstream applications, build tooling and example-only changes have explicit applicability dispositions.
