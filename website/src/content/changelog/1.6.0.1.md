PiSharp 1.6.0.1 is a C#-only patch release on the unchanged Pi v1.6.0 and Pi Durable 1.6.0 baseline. All 31 packages (29 libraries, `PiSharp.Cli`, and `PiSharp.Templates`) are available on NuGet. It graduates seven Tier-1 `[Experimental]` diagnostic IDs to stable, completes Durable 1.6.0 host/workflow wiring and storage indexing, fixes transport retry classification, and trims the CLI tool archive. See the [release notes](https://github.com/jkelly/PiSharp/blob/main/docs/release-notes/1.6.0.1.md) and [publication evidence](https://github.com/jkelly/PiSharp/blob/main/AI_DOCS/release-1.6.0.1-publication-results.md) for full details and validation boundaries.

### Ecosystem, telemetry, and API graduation

- **`PiSharp.Extensions.AI`:** new library bridging PiSharp transports and embeddings with `Microsoft.Extensions.AI` (`PiChatClient : IChatClient`, `PiEmbeddingGenerator`, `ChatClientTransportAdapter : IChatTransport`, and DI helpers). See [Microsoft.Extensions.AI](/docs/embed/extensions-ai/).
- **`PiSharp.Templates`:** new `dotnet new` template package providing `pisharp-agent`, `pisharp-extension`, and `pisharp-workflow`. See [Project templates](/docs/embed/sdk/#project-templates).
- **`DiagnosticsTelemetry`:** zero-dependency opt-in `ActivitySource` and `Meter` adapter in `PiSharp.Telemetry` passing all 11 conformance groups. See [Telemetry](/docs/embed/telemetry/).
- **Tier-1 `[Experimental]` graduation:** removes `[Experimental]` from `PISHARP_SCHEMA001`, `PISHARP_IDENTITY001`, `PISHARP_TIERS001`, `PISHARP_AI001`, `PISHARP_AUTH001`, `PISHARP_EXEC001`, and `PISHARP_TOOLSEARCH001` ([Decision 0017](https://github.com/jkelly/PiSharp/blob/main/docs/decisions/0017-experimental-graduation-tier1.md)).

### Durable, runtime parity, and packaging

- **Durable 1.6.0 end-to-end wiring:** adds HTTP/device/web signal delivery, `SubmissionDraft.Notify` and `OnAbort: keep`, opt-in `FitImages`, `imageUnsupportedByModel` and `YieldAnswer` rendering, and signal-based `WaitForSignal` workflow pauses in `PiSharp.CustomAgents`.
- **Storage performance:** adds byte-offset indexing with a bounded LRU cache to `JsonlStorage` and SQLite group commit coalescing to `ChordStore`.
- **Transport retries and tools:** retries transient connection drops across OpenAI Completions, Anthropic Messages, Google Generative AI / Vertex, and Mistral Conversations while keeping sanitized error messages unchanged ([Decision 0016](https://github.com/jkelly/PiSharp/blob/main/docs/decisions/0016-transport-retry-classification.md)); adds a native PowerShell tool, brings `FindTool` anchoring into parity with `PiFindTool`, and wires native C# extension overrides (`omitReplacedExtensions`) plus `/reload` diagnostics.
- **Packaging and release tooling:** strips native `.pdb` files and unused RID native assets from `PiSharp.Cli` (enforced under an 80 MiB budget), adds standalone archive + Homebrew/Scoop/Winget manifest builders, and adds automated post-publish verification for all 31 packages.
