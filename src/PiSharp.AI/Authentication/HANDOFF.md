- Workload identity federation (0.99.2): `ResolveAnthropicApiKeyAsync` now ends with the federation step from `providers/anthropic.ts`. - `AnthropicWorkloadIdentityFederation` ports `getAnthropicFederation` and three parts of the Anthropic SDK 0.129.0: the exchange (`oidc-federation.ts`), the token cache (`token-cache.ts`) and token application. Token application sends a Bearer token and appends the `oauth-2025-04-20` beta. - Request path: `AnthropicInjectedTransportAdapter` admits the secretless federation result and its binding carries the `AnthropicFederationConfiguration`. `AnthropicMessagesAuthenticatedRequestFactory` uses it only when the request options' headers own no authorization, x-api-key or cf-aig-authorization value (upstream `hasRequestAuth`). Key, bearer and OAuth paths are unchanged. The CLI live route now resolves Anthropic through `AnthropicLiveAuthentication` (stored auth.json credential, then this resolver over the session's process environment) at start and before every request, and connects through `AnthropicResolvedTransports`, so federation, environment tokens and stored OAuth (refreshed per request) reach production requests.
