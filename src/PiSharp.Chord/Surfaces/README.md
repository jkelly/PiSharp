# Portable surfaces

This namespace ports the portable behavior of Chord 1.5.2's `surfaces/*`: script-set contracts, complete-set native facet loading, client link/reconnect/update ownership, theme and locale preferences, local registries, message catalogs, render-scoped formatting and per-host page state. `Client` loads trusted managed registration callbacks; it does not evaluate downloaded JavaScript or turn a managed assembly into a browser script. It reuses the host's link protocol and never replays calls.

`IClientStyles` is a platform adapter contract. A web implementation must preload CSS without applying it and settle only the plugin versions the host accepted. This assembly has no DOM, HTML `lang`/`dir` writer, `matchMedia`, React hooks, ESM/CommonJS module interop, browser script injection, Node permission model or secure terminal plugin evaluator. These are platform-specific and perform no implicit work here. `Registered.Source` only emits the JavaScript registration wrapper for a separate builder; `Registered.Evaluate` invokes a native delegate with an explicit module allowlist. That allowlist is a dependency boundary, not a security sandbox.

`LoopEnvironment` supplies real .NET timers and accepts explicit online/wake signals. Browser visibility and network event listeners must be supplied by a browser adapter. `Themes.Variables` returns the CSS variables for an actual DOM adapter; `Themes.TerminalColor` returns truecolor or nearest xterm-256 SGR parameters. Neither writes a screen or changes browser state. Active language exposes `Locale` and `Dir` for those writers. Date and number formatting uses .NET's locale database and formatting patterns, scoped to synchronous rendering on the current thread; it does not mutate the process culture.

`PageStates` keeps arbitrary native values by host/key across facet reloads and clears them on host close. It is distinct from replicated/persisted state. Theme and locale choice facets use real persisted Chord documents, bounded to the 10,000 most recent choosing canonical principals. Applications explicitly install the facets they want.
